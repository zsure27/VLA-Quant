# 059：12L 全语言 W2 层 Recovery-LoRA 闭环结果

## 问题与固定条件

本轮只问：在 exact-12L AWQ-W2A16 混精底座上，把 rank8 Recovery-LoRA 从 C3 的 blocks18–19 扩到全部仍为 W2 的语言 blocks（0–7、16–19、24–31），能否以小于直接提高权重精度的部署代价获得稳定闭环收益？DINO W2 G64、SigLIP W2 G128、语言 W4 blocks8–15/20–23、MLP clip、attention V/O 无额外 clip 和保护模块精度保持不变。新 adapter 覆盖 20 个语言 block、140 个 Linear、12,492,800 个可训练参数，rank8，1000 步、80 个训练 reset 的学生访问观测及同观测 BF16 教师标签，Smooth-L1 beta0.1。序列化 adapter 为 25,086,682 字节。相对 C3，目标范围和参数预算同时改变；这里测得的是实际工程组合效果，不能把收益单独归因于覆盖范围。

评测为 LIBERO Spatial 官方 reset20–49，10 任务各 30 回合，五配置使用相同 task/reset、初态 SHA、逐回合 model/env seed 和 8 步动作 chunk。它们是**复用的开发初态**，不是独立 A1、盲测或新的训练数据留出。`offline_final_holdout` 未触碰。训练、微测、修正首片和剩余片均由不可变顺序计划执行，所有 GPU 阶段退出码为 0。

LW 相对 C0 为 **45 rescue / 5 break，净增 40**；配对 exact McNemar p=4.21×10⁻⁹。任务聚类 bootstrap 的净增比例 95% 区间约 **0.3 至 32.7 个百分点**，区间很宽，不能把逐回合 p 值当作跨任务、跨初态泛化保证。C3 相对 C0 为 25 rescue / 9 break、净增 16；任务聚类区间约 −1.0 至 13.0 个百分点。LW 相对 C3 为 30 rescue / 6 break、净增 24。

## 协议门禁与异常

10 回合/配置微测通过了输入哈希、初态/随机流、首个策略观测、8 步 chunk 和 7D 有限动作检查。原 `first50-v2` 虽每配置完成50回合，但实际命令未开启 `--trace-observations`，不能核对新增 reset21–24 的策略可见初观测；它仅保留为开发诊断。版本化 `first50trace-v3` 在相同条件下独立输出并补齐观测记录，其五配置逐回合成败标签与 v2 **逐字节一致**。v3 250 回合硬门禁通过后才运行 `remaining250-v2`。正式300回合/配置只合并 `first50trace-v3` 与 `remaining250-v2`，不叠加微测或 v2 的重复回合。原始逐回合配对表、配置、命令及结果 SHA 在同名 `results/experiments/p2-shared-peft/20260930-059-language-w2-all/paired-spatial300-analysis.json`。

## 研究判断与下一步

本轮支持：**扩大语言 W2 范围的单个共享 LoRA 在复用开发初态上有明显闭环收益，已逼近 BF16/W4；当前没有必须引入 Router 的证据。** C3 的局部微调收益和范围局限被直接量化。仍需真正不同且与训练/开发无重叠的环境条件来验证 LW 的泛化；`env_seed` 单独变化已证实无效，不能再作 A1 替代。

下一轮按证据推进：

1. 首先构造**策略可见确实变化、可重复且与训练/开发不重叠**的新 reset/环境条件，按 `docs/EVALUATION_SMOKE_GATE_20260929_CN.md` 做无模型同条件复测、配对策略微测与最多50回合硬门禁，再评 C0/LW/BF16/W4。当前结果不能代替这一步。
2. 视觉 LoRA 作为**增量实验**：冻结 LW 的语言 adapter，只增加有清晰模块清单和参数预算的视觉 rank8 adapter；同一训练观测、教师、步数和评测条件，先做形状/零残差/重载契约及10步训练烟雾。当前实现的 LoRA 状态加载器和训练目标选择器只允许语言层，必须先版本化实现并通过门禁，不得直接开长评测。比较 LW 与 LW+Vision 的 rescue、break、净收益、时间/参数/字节成本；剩余 8/300 的 BF16 净差是本切片的描述性余量，不能作为保证。
3. 纯 W2 是单独版本化 backbone 阶段；先检查全 W2 量化、adapter 覆盖和加载等价，再做短烟雾与配对闭环。12L 的 LW adapter 直接迁移到纯 W2 只能作为转移诊断，不等于在纯 W2 上完成微调。
4. 只有在新条件下仍出现可复现、可由动作前 H17/视觉/本体环境信息预测的互补，并且相对最强静态共享 LoRA 有净收益及合理部署成本时，才进入专家互补与 Contextual Routing 门禁。不得以任务 ID 记忆替代上下文路由。
