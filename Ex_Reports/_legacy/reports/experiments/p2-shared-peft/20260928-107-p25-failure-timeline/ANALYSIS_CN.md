# P2.5 学生访问状态失败时序回看

复核对象为此前 10 个历史/开发 reset 的 data80 rank8 LoRA 学生闭环、140 次真实重推理观测及同观测 BF16 查询。原始捕获在本机被 Git 忽略的 `backups/experiments/p2-shared-peft/20260927-107-p25-and-matrix/`，逐次派生数据见同名 `results/experiments/p2-shared-peft/20260928-107-p25-failure-timeline/timeline.json`。本次仅重新分析既有资料，不增加独立样本。

10 回合中失败 1 回合（serial 1，28 次查询）。在该失败回合的 LoRA 学生访问观测上，LoRA 与 BF16 的平均原始动作 MSE **低于**未加 LoRA 的同状态探针，平均差约 −0.0235；LoRA 第一次与 BF16 夹爪二值动作不同出现在第 2 次查询，而未加 LoRA 探针在第 0 次查询就不同。这说明平均同状态误差改善本身无法解释闭环失败；探针不构成无 LoRA 的独立闭环轨迹。

按执行的 8 步 chunk 位置汇总 140 次查询，模型输出在第 7 步的夹爪二值分歧为 15.0%，第 6 步为 7.86%，第 3 步仅 0.71%；第 7 步夹爪 RMSE 0.438，第 3 步 0.093。位置误差也在 chunk 两端偏高。二值判断与实际 OFT 评测器一致：模型原始夹爪值以 0.5 阈值二值化，随后 OpenVLA 符号翻转。评测器正常执行完整 8 步后才重推理。这些数据提示晚期 chunk 控制是值得检查的失效窗口，**尚不能认定其导致失败**。

局限：捕获不含任务阶段和首次实际失败时刻标注；大分歧阈值未预注册，因此不补造首次大分歧事件；仅 10 回合且开发 reset；没有对应无 LoRA 的闭环轨迹。下一步以同一 evaluator 的 12L/12L+LoRA/14L 完整配对开发评测检验是否存在 headroom 与稳定成功率收益。若仍无闭环收益，再优先进行 student-state BF16 重标与同 rank8 训练控制，不进入 Router。
