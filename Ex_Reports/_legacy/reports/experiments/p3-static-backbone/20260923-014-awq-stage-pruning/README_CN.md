# 2026-09-23 014：完整 W2 的语言 W4 层数裁剪

固定完整模型底座为语言 W2 G64 attention-only no-clip、DINO W2 G64、SigLIP W2 G128；选中语言 block 使用独立 W4 profile 的完整 scale、clip 和 G128 分组。评测为 LIBERO Spatial 官方初态 5–9，使用配对 seed 和 manifest。

## 完整 50 回合结果

| W4 语言块 | 层数 | 成功回合 |
|---|---:|---:|
| 16–23 | 8 | 28/50 |
| 12–23 | 12 | 39/50 |
| 12–19 | 8 | 16/50 |
| 8–15 + 20–23 | 12 | **42/50** |
| 8–11 + 16–23 | 12 | 40/50 |
| 8–11 + 20–23 | 8 | 36/50 |
| 12–15 + 20–23 | 8 | 37/50 |
| 10–15 + 20–23 | 10 | **39/50** |
| 8–13 + 20–23 | 10 | 38/50 |

前一轮同协议的 16 层 `8–23` 为 44/50。当前最优裁剪是 12 层 `8–15 + 20–23` 的 42/50：相对 16 层只少 2 次成功，同时少保护 4 个 block。继续裁到 10 层时，保留 `14–15` 的 `10–15 + 20–23` 为 39/50；保留 `8–9` 的 `8–13 + 20–23` 为 38/50，因此在这组配对中 `14–15` 略重要于 `8–9`。

`12–19` 只有 16/50，而加入 `20–23` 的 `12–23` 达到 39/50，说明后四层存在显著的闭环交互作用。单独四层的 10 回合筛选最高仅 6/10，不能通过单窗口分数做加性预测。短筛与完整结果也有明显偏差，例如 `8–11 + 20–23` 从 8/10 降到 36/50；后续选择必须以完整分片确认。

## 完整性与边界

- 本轮共 22 个分片、580 回合，全部 `exit-code=0` 并写出 `EXECUTION_COMPLETE`。
- 22 份动作 trace 共 10,020 次策略查询；动作 chunk 为 8×7，动作与查询时 proprio 均 finite。
- 580 条视频 manifest 已逐文件计算 SHA256；其中 521 个不同内容哈希，重复内容来自配对候选间的相同轨迹，不代表缺失文件。
- 结果仍是混合 W2/W4 fake quant，不代表均匀 W2，也没有测 packed kernel 的速度、显存或端到端吞吐。
- 各候选共享配对初态，适合逐候选差值比较；当前 50 回合规模不足以把 1–3 次成功差异解释为稳定显著性。
