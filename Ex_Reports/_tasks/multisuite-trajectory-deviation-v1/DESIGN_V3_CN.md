# v3：跨模型、跨量化方法的运行时轨迹偏移共性

## 结果与当前完成范围

当前没有服务器、没有GPU实验，也没有新的跨模型实测结论。已实现独立CPU测量合同、六组分布/响应图与合成预览；π0.5、GR00T-N1.5及其ActQuant、SmoothQuant、QuantVLA的原生采集/量化适配尚未实现。v1/v2的OFT采集绑定不能直接用于这两个模型。

## 对DyQ-VLA第3节的理解修正

固定阅读版本：[DyQ-VLA v3，第3节与附录B/C](https://arxiv.org/html/2603.07904v3)。论文中π0.5与GR00T-N1.5是模型，LIBERO是benchmark；四suite是任务集合，不能称四个独立benchmark。

1. 第3节的运行时误差不等于“量化动作减去BF16动作”。全精度也存在预测、控制执行和接触带来的误差。核心实验在**同一精度**下，从匹配初态分出无扰动与有扰动轨迹；扰动后各自读取自己的新观测闭环执行。
2. 查询t执行后形成的位姿误差，对应**下一次查询t+1**的动作响应。预测动作、实际执行位姿及二者的时间先后必须分开。
3. 论文观察到平移分布较分散，旋转分布的中心随执行推进；量化主要放大平移离散度/响应，旋转模式的变化相对小。它不是“量化导致全部旋转漂移”，也没有证明每条轨迹都出现两个固定时间拐点。这里把这些作为待检验假设，允许没有明显窗口、方向相反和模型特有结果。
4. 论文LIBERO原生执行前缀：π0.5为5步、GR00T-N1.5为1步。不能沿用OFT的8步，也不能把相同query编号当作相同物理时间。图按模型分面，并另存control_step、仿真秒数、模型内部flow/denoising步，禁止混用。
5. 论文任务表中的示范轨迹参考、成功轨迹统计，不是第3节受控扰动参考。我们的诊断保留成功、失败、异常和中断，分别列分母，不只挑成功回合。

## 首轮对象与分层预算

| 维度 | 主设计 |
|---|---|
| 模型 | π0.5与GR00T-N1.5，分别固定适配LIBERO的实际checkpoint、源码commit、动作统计和控制器SHA；GR00T不能用更新主分支型号替代N1.5 |
| 测试集 | LIBERO Spatial、Object、Goal、Long（代码libero_10），development角色 |
| 首批任务 | 每suite固定task0和task5、各一个配对初态reset5；起跑前核对任务语义及数据角色。若角色冲突，按无标签固定规则替换并预登记 |
| 条件 | BF16、ActQuant-W4A16、SmoothQuant-W4A8、QuantVLA-W4A8 |
| 为什么这样选 | 权重量化、通用权重/激活量化、VLA专用权重/激活量化各一类；优先获得足够长的可观察轨迹。AWQ-W4A16可作为严重退化压力对照，HoloQ-W4A4可作为更低激活位宽扩展，不默认增加 |
| 主采集预算 | 2模型×4条件×4suite×2任务×1初态=**64个自然闭环回合**，逐模型顺序加载；不是先跑一个suite再决定是否展示其他suite |
| 复查 | 先看覆盖与重复性。现象明确则停止；只有区分假设需要时增加reset6或任务覆盖，每次独立注册，不能以结果好坏挑任务。全部40任务同一初态的自然闭环上限320回合，仅为可选扩展，不是执行目标 |
| 暂不做 | 全方法位宽网格、W2恢复训练、LoRA/OPD、动态精度、RoboTwin全量实验；RoboTwin是后续独立benchmark扩展 |

上述64回合主要描述自然轨迹，不能单靠这些轨迹复现第3节的受控扰动结论。若原生接口通过且预算允许，再运行独立短探针：每suite固定task0、reset5，两个模型、BF16/ActQuant/QuantVLA三条件；每格Tz+、Tz−、Rz+、Rz−四个单独分支，共**96条短扰动分支**，不是96条完整任务。每个分支注入后最多40个控制步；π0.5可分析0–8次查询，GR00T另报告相同物理时长与相同查询数两个视角，不混合斜率。

24条无扰动参考优先复用自然闭环，仅在完整输入/状态/控制器/队列/RNG和查询时刻一致的CPU/GPU重放门禁通过后允许复用；否则额外采24条短参考。前缀重放96次的成本也需计入；不能只把注入后的40步当总成本。任一接口/预算缺失就停止在64回合自然诊断，不用自然分支冒充扰动实验。

扰动时刻首批固定query4；不同模型对应20/4个已执行控制步，不能据此比较相同任务阶段。幅度首批为独立校准量纲的0.1倍，并记录转换后的米/弧度、实际实现误差与控制器饱和；不是给动作直接加0.1就称0.1米。z轴正负只是小规模探针，不能推广到全部六方向。时刻、幅度、方向的扩展一次只改一个因素。

## 三类参考必须分别命名

| 参考 | 回答的问题 | 局限 |
|---|---|---|
| 自然闭环：量化与BF16配对初态 | 两种策略最终走向哪里、在哪些阶段分叉 | 状态已经分叉，含反馈效应，不是局部纯量化误差 |
| 同观测：量化与BF16顺序重放 | 同一输入下预测动作差在哪里 | 离线动作差不等于真实执行位姿误差，不加到闭环分母 |
| 受控扰动：同一精度的扰动/无扰动分支 | 模型怎样响应已出现的位姿偏离，量化是否改变响应 | 需要完整可重放状态、共同随机数与原生控制器验证 |

flow模型的噪声身份按查询记录、匹配，不靠一条总seed声称相同。采集器开/关必须验证输入、动作、调用次数、执行前缀、随机数和保存重载相同；每种方法需要自己的真实profile和目标模块清单。不同方法若保护模块或量化粒度不同，只能解释为完整配方比较，不能把效果全部归因于方法名称或激活位宽。

## 测量与统计合同

- 位姿：平移欧氏距离用米存储/毫米展示；旋转用SO(3)测地角和世界坐标Log向量，用弧度存储/度展示。四元数q与−q等价，不直接减Euler角，不把旋转命令L2称姿态角。范数分布中心移动不能证明有符号同向漂移，有符号分量需结合v2轨迹图。
- 归一化：每模型独立冻结sT、sR、六维动作尺度sA，所有精度/时间/方向共用。按独立平衡校准集的chunk位移p95和动作1–99百分位半幅估计，保存实际来源、样本数和SHA；近零尺度拒绝。论文大规模校准预算不直接照搬，本研究不默认再跑512条FP轨迹。
- εT=eT/sT、εR=eR/sR。ΔA为下一query预测的原生执行前缀内，六维运动通道差除以sA后，先平方求和再对前缀取均值开方；平移/旋转分量另列，夹爪排除并单独记录。
- 敏感度ST=ΔA_all/εT、SR=ΔA_all/εR，分子均为六维运动响应。近零分母记undefined，不能补零。它是有限扰动响应比，不是严格偏导或真实动力学稳定性证明。
- 均值、标准差、分位数来自原始episode标量；KDE仅帮助展示，正边界反射、同一比较组固定带宽和坐标。图中25%/60%峰值等高线不是置信区间。
- 相同方向内，主要演化图固定所有展示时间与精度均完整的配对cohort；同时保存available-case统计、每query风险集、失败/异常/缺失原因，防止完整样本选择被隐藏。若压力方法让完整cohort归零，报告不可比较并单独展示其缺失，不延长轨迹补造数据。
- 先逐任务/初态描述，再看suite和模型间效应方向。帧不是独立样本；首批每suite仅两个任务，不给跨benchmark普遍性或稳定显著性结论。后续复查足够后按任务聚类给区间；不按帧bootstrap。负向扰动单列，不能正负混合抵消。
- 共性候选：平移分布方差相对FP倍数、旋转中心前后变化及其超出FP的部分、平移响应比、持续越阈窗口、夹爪事件前后变化。允许逐渐漂移、无窗口、任务例外；不强制寻找两个拐点。

## 可视化组织：先看轨迹，再看分布，最后看共性

1. **具体轨迹**：沿用v2三维+XY/XZ、误差局部放大、带符号平移/旋转曲线、夹爪切换、query/chunk遮罩和同步滑块。模型后端接入前只展示合成预览，不把OFT合成图标为π0.5实测。
2. **14联合分布演化**：当前误差对下一query动作响应，早/中/晚固定轴、BF16虚线与量化实线、均值点。默认SQ作为预登记示例，不按效果最大者挑方法。
3. **15中心、16离散度**：所有方法分面，两模型独立；明确是跨配对轨迹的分布，而非单条轨迹滑窗。
4. **17响应敏感度**：看相同误差下动作是否过度响应；不能仅凭相关性称为反馈增益或因果机制。
5. **18共性矩阵**：suite×方法，两模型分行；平移方差Q/FP、旋转额外中心变化ΔQ−ΔFP、平移敏感度配对比。相同指标共享色标，保留NaN和分母。
6. **19风险集**：展示何时失去有效观测；与固定cohort结果一并阅读，不能只展示“漂亮”后期曲线。

预览入口：[六组v3图](preview-v3/index.html)。当前为手工构造分布的科学作图示意，**不是模拟器数据、论文复现、模型预测或已发现的共性**。每幅PNG/PDF均标注SYNTHETIC DEMO。负方向用CLI另输出，禁止用正向图替代。
