## DuQuant准备的准确边界

共同目标头部元数据为420个Linear和2个patch Conv，共422项；实际输入宽度为588、1024、1152、4096、4304、11008。按整除关系显式选择旋转block4/16/128；该选择是OFT形状适配参数，并不冒充论文原参数。原始量化/旋转/置换函数保持固定源码；隔离导入后加载受SHA约束的自产旋转常数，不依赖进程工作目录去找Rot.pkl。

CPU数据全部是合成合同夹具、输出维度缩小为9，标签中的calibration_reset0只用于校准/评测角色合同检查，**不是实际reset0模型标定样本**。小模块采用4次旋转搜索检查公式，不是全模型256次原配方。当前绑定不含LET/LWC、完整原始decoder-block优化或注意力matmul路径，所以不会用这个核心组件代替完整DuQuant，或把CPU PASS说成全模型兼容。OFT现有两层patch实际均为14×14/输入588，16×16只是额外回归夹具。
