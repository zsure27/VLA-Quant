# VLA-Quant 基线实验进展与下一轮规划

截至 2026-09-29。本文汇总**已完成的原始实验**，不把不同 session 的结果拼成新配对样本。目标是以尽可能低的训练、存储和推理成本，恢复 AWQ-W2A16 OpenVLA-OFT 的闭环能力。当前方法开发固定在 12L 混精底座；纯 W2 是后续独立目标。所有下述 Spatial 0–49 结果均为历史/开发证据，`offline_final_holdout` 未触碰，不称最终盲测。

用户进一步确定先让 12L/C3 向 BF16 闭环能力靠近，再考虑纯 W2；是否引入 Router 取决于互补与上下文可预测性，而非方法名称。具体增量决策见[12L/C3→BF16 恢复规划](../../../docs/C3_TO_BF16_RECOVERY_ROADMAP_20260929_CN.md)。

## 1. AWQ 与静态底座：量化损伤在哪里

| 配置与范围 | 闭环成功 | 可得结论 |
|---|---:|---|
| BF16，Spatial 官方初态0–49 | 487/500（97.4%） | 高精度参照 |
| AWQ W4A16，同500 | 486/500（97.2%） | 当前 W4 fake-quant 配方与 BF16 接近 |
| 仅视觉 W2：DINO G64、SigLIP G128，语言 BF16，同500 | 460/500（92.0%） | 视觉 W2 可运行，但比 BF16 少 27 次成功；不能称无损 |
| 仅语言 W2 G64、attention V/O 无额外 clip，视觉 BF16 | 29/50（初态5–9）；49/100（10–19） | 语言 W2 是主要瓶颈；两片不合并为盲测 |
| 完整 W2 原始 G128，初态5–9 | 0/50 | 原配方在此小片严重失效 |
| 完整 W2 G64、attention 无额外 clip，初态5–9 | 11/50 | 有部分恢复，但仍不足以作强底座；此格 SigLIP 也为 G64，不能单独归因于语言 clip |

视觉分组在完整 W2 小片上为 DINO128/SigLIP128 `3/50`、DINO128/SigLIP64 `1/50`、DINO64/SigLIP128 `10/50`、DINO64/SigLIP64 `11/50`，支持 **DINO G64** 是这一组消融中的主要改善来源。语言 attention 撤销额外 clip 的开发片为 `29/50`，MLP 撤销 clip 为 `0/50`；因此应保留当前按模块区分的 clip 配方，尚不能宣称 scale、clip 或 group size 已经全局最优。所有结果基于 BF16 存储的 fake quant，**未证明真实 INT2/INT4 内核的字节、显存或加速收益**。[原始基线报告](../../experiments/p0-foundation-baselines/20260918-107-awq-continuation/README_CN.md)。

语言 W4 保护层的完整 Spatial500 历史结果如下；三者均保持 DINO W2 G64、SigLIP W2 G128，保护模块高精度，语言其他层 W2 G64：

| 静态配置 | W4 语言 blocks | 成功/500 | 职责 |
|---|---|---:|---|
| 12L | 8–15、20–23 | 412（82.4%） | P2/P2.5 唯一默认混精底座，18–19 仍为 W2 |
| 14L | 8–15、18–23 | 431（86.2%） | 只把 18–19 升 W4 的静态恢复参照 |
| 16L | 8–23 | 434（86.8%） | 较强静态参照 |

这组历史 12L→14L 差值为 `+19/500`，14L→16L 为 `+3/500`。[静态配对来源](../../experiments/p3-static-backbone/20260924-107-awq-stage-complete/README_CN.md)。另一次 P2.5 **同评测器**配对得到 12L `411/500`、14L `431/500`，headroom 为 `+20/500`；Scale 对照还记录过 14L `430/500`。`411/412` 与 `430/431` 的跨 session 漂移尚未完成逐项来源审计；只在同一次严格配对中计算差值，不能任选有利分母。12L 是 **W2 主导的 W2/W4 混精模型**，绝不是纯 W2。

## 2. 数据与 shared PEFT：离线改善为何不够

P1 将 432 条轨迹、52,970 个 transition 按整轨迹分成 `peft_train/router_dev/offline_final_holdout=298/59/75`；量化等价、零输出、梯度和重载契约通过。Scale-PEFT 对 blocks18–19 的 14 个 Linear 有 6,324,224 个可训练残差，LoRA rank8 为 1,249,280 个可训练参数。P1 只验证实现和数据边界，不构成控制性能结果。[P1 报告](../../experiments/p1-data-contract/20260925-107-p1-data-contract/README_CN.md)。

| 方法与证据范围 | 12L 对照 | 候选 | 判断 |
|---|---:|---:|---|
| Scale-PEFT，历史配对 Spatial500 | 411/500 | 407/500 | 固定观测误差降低，但无净闭环恢复；保留为负基线 |
| 旧 demo-only rank8 Recovery-LoRA，同评测器 Spatial500 | 411/500 | 408/500 | 救回25、新增失败28，净−3；95%配对区间 −3.4 至 +2.4 pp；未过 shared gate |
| data80 LoRA 50 回合稳定性 pilot，初态0–4 | 43/50 | 42/50 | 同片 14L 也为43/50，静态 headroom=0，恢复率必须为 `null` |

旧 LoRA 的同片静态 14L 为 `431/500`，相对 12L 有 `+20/500` headroom；其 `−3/500` 不应与历史 412 分母混算。[500 回合配对分析](../../experiments/p2-shared-peft/20260928-107-p25-paired-headroom/POST_RUN_ANALYSIS_CN.md)；[50 回合 pilot](../../experiments/p2-shared-peft/20260926-107-p2-data80-stability-and-realignment/README_CN.md)。

旧 data80 方案从 16 轨迹/200 步变为 80 轨迹/1000 步，**覆盖与计算量同时改变**，不能把改善单独归于数据量。补齐的 `16/200、16/1000、80/200、80/1000` 四格在相同 59 条 router_dev 轨迹、295 帧上的动作 MSE 分别为 `0.05195、0.06943、0.05485、0.05173`，12L 为 `0.05549`。80/1000 虽有较低均值，但只改善 52.5% 的轨迹，最差十分位退化均值 `+0.01681`；16/1000 明显退化。覆盖或步数均非单调收益，离线均值不能替代闭环。[四格结果](../../experiments/p2-shared-peft/20260927-107-p2-router-dev/POST_RUN_DECISION_CN.md)。

对任务1/2早期学生观测的单变量位置权重2目标曾使任务2部分位置误差降低，却把同观测夹爪符号分歧从旧 LoRA 的 `0.01042` 推高到 `0.43042`；该候选**被离线门禁否决，没有闭环成功率**。[目标诊断](../../experiments/p2-shared-peft/20260929-107-p25-position-weight2/POST_RUN_ANALYSIS_CN.md)。这些负结果支持优先修正训练观测分布，而非继续做 rank、Scale、clip 或损失权重网格。

## 3. 学生状态重标 C3：有开发集闭环信号，尚无独立复现

C3 保持 exact-12L、语言 blocks18–19、rank8、Response-SVD 初始化、1000 步与原 uniform Smooth-L1；将训练输入改为在**训练 reset0–3** 由旧学生实际访问的每任务 4 回合 query0/1，共 80 个观测，并由冻结 BF16 在同一观测生成动作标签。C3 adapter SHA256=`67cd6a6d4ec75d9173ce95b5f8f21c99b6562bfea58ea80947aa5640a335710a`，文件 2,508,930 bytes、1,249,280 个可训练参数。评价使用未参与 C3 训练的官方 reset5–49，10 任务×45 初态；这些初态仍被项目反复用于开发，不是独立最终 holdout。[107 原报告](../../experiments/p2-shared-peft/20260929-107-p25-student-state80-distill/POST_RUN_ANALYSIS_CN.md)。

| 同条件配置 | 成功/450 | 相对 C0 |
|---|---:|---:|
| BF16 | 438 | +70 |
| C0：12L | 368 | — |
| C1：旧 LoRA | 366 | −2 |
| C2：静态 14L | 388 | +20 |
| C3：学生状态重标 LoRA | **389** | **+21** |

C3−C0 为 `+21/450`（+4.67 pp）：**救回35、新增失败14**，原报告的逐回合配对 bootstrap 95%区间约 `+1.56 至 +7.78 pp`、精确 McNemar `p=0.00380`。这是一套开发条件的统计描述，不是跨独立评测条件的置信保证。任务1净增14、任务5净增9，两项合计超过总体净增21；任务3/6/7分别净退2/3/4。C3 与14L只差 `1/450`（两者配对 `p=1.0`），不能声称 C3 优于 14L。`21/20=105%` 仅是该开发集合上的描述性静态 headroom 比值，并非已复现的恢复率。C3 仍比 BF16 少49回合。

**A1 独立性失败：**110 冻结上述五配置，拟仅将 `env_seed=0→1`，再次各评450回合（总计2250次运行，其中 C0/C1/C2/C3 的1800次可与107逐回合交叉核对）。四个可对照配置共1800个逐回合成败标签与107旧轮**全部相同**；三个同边界 C3 策略 trace 逐字节相同。原预检查省略了真实评测器在 `env.seed` 后调用的 `seed_all(model_seed)`；按真实顺序抽查10任务 query0及固定后8步，两路图像、proprio和sim状态哈希均相同。因此判为 `A1_INVALID_CONDITION`：110 运行是协议回归，**不是新的450个独立样本/配置，也不为C3添加第二次收益验证**。全部450回合图像没有逐帧哈希，不能将三片 trace 等同扩展为全程逐字节证明。50回合稳定性 pilot 使用初态0–4，与此处5–49不同。[A1完整审计](../../experiments/p2-shared-peft/20260929-110-a1-envseed1/README_CN.md)。

## 4. 当前结论、成本与限制

1. 量化瓶颈主要在语言路径；12L 是用于研究低成本恢复的稳定**混精**底座，14L/16L 是静态参照。当前未证明视觉 group、语言 scale/clip 是所有候选中的最优配置，也未得到可用的纯 W2 全模型。
2. 旧 Scale-PEFT 与旧 LoRA 的离线教师动作改善都未稳定转成闭环净收益。C3 的学生状态重标在单套开发评测上出现明确正信号，支持“观测/目标对齐值得研究”，但不能唯一因果归因于 covariate shift，也不能称已经跨条件稳健。
3. C3 仅增加约125万参数、实测 adapter 文件约2.51 MB。理想纯权重估算中，blocks18–19 从 W2 升 W4 约增加101.19 MB，C3文件约为其2.48%；**这不是实际部署内存/延迟比较**。三份 AWQ profile、fake-quant 容器、模型常驻量、每8步 chunk 的延迟和真实低比特 kernel 性能仍须同协议实测。[成本来源](../../experiments/p2-shared-peft/20260926-107-p2-data80-stability-and-realignment/README_CN.md)。
4. P4 两专家互补和 P5 Router 均未启动。任务间收益与失败翻转不能当作当前观测可预测的路由证据；未来必须优于 Always-C3、最佳固定方法及 task-ID/instruction-only 对照，并仅使用决策前可观测的 H17/proprio，不使用未来成功或 GT。

## 5. 后续实验顺序与停止条件

| 顺序 | 只回答的问题与动作 | 放行条件 |
|---|---|---|
| A1 条件修复（先做，无需训练） | 寻找来源清楚的**单一**新评测条件：优先取得不与训练/开发重叠的初态数组；若不可得，预注册 `set_init_state` 后的一种可复现扰动及幅度。冻结 C0/C2/C3、评测器和其余条件，保存新旧初态/观测哈希与重叠审计。 | 按[长评测烟雾门禁](../../../docs/EVALUATION_SMOKE_GATE_20260929_CN.md)先核对真实评测调用顺序、同条件重复、10任务小样本 query0/后8步差异，再做 C0/C3 配对策略微型闭环；首片最多50/配置且必须复核实际 trace。任何一关失败就停止 GPU 扩展并收尾。仅更换 env_seed 已证实无效，不重复。 |
| A1 独立闭环 | 只有新条件通过时，冻结 C3、C0 和14L/BF16参照，预注册独立条件的配对长评测；报告任务分层、救回/新增失败、95%区间与成本。 | C3−C0 为正、预定区间下界>0、至少两个任务净改善，且独立条件与物料门禁均通过，才称收益复现；相同标签也不能单独否定条件，需看实际观测和 trace。 |
| A2 训练稳健性 | 仅在有效 A1 后改变**训练 seed**，保持训练样本、标签、rank8、blocks18–19、训练步数、损失与评测条件不变。 | 有受控收益才保留 shared PEFT；否则回查训练状态分布及任务6/7退步，不扩大 rank 或专家。 |
| 条件扩层 | A1/A2 与 BF16 缺口归因完成后，若误差指向其他 W2 block，预先选定一组新增层；先以近似同参数的4 blocks/rank4对照2 blocks/rank8，再用4 blocks/rank8对照2 blocks/rank16分离覆盖与容量。 | 固定训练观测/步数/教师，逐项核算参数和实际文件字节；离线尾部、夹爪与独立闭环均通过才保留，不展开层组合网格。详见[扩展规划](../../../docs/C3_TO_BF16_RECOVERY_ROADMAP_20260929_CN.md)。 |
| 机制与 Router 门禁 | 对 C3 自身访问状态查询 BF16，标记首次动作/控制大分歧、8步位置、7D位置/旋转/夹爪，重点审计任务1/5改善和3/6/7退步；随后检验同任务内可预测的 OFF/ON 互补。 | 先处理目标/分布错配，并证明超出任务固定选择的上下文信息；否则不做 P4/P5。Router 必须和 task-ID/instruction-only、Always-C3 比较。 |
| 后续扩展 | 方法在12L上稳健后，逐步减少 W4 保护向纯W2推进；SmoothQuant的scale/clip/激活量化另立数值等价与成本实验。 | 每一版有新底座和严格配对基线；不把12L写成纯W2，不重新展开静态W4组合搜索。 |

本报告不启动实例或 GPU。110 已取得原生关机请求执行回执、低频心跳已暂停；平台控制台 OFF/停止计费未独立核验。下一次由用户开启具体实例后，再执行新的 PRE-RUN CARD 与烟雾门禁。完整视频、动作 trace、模型和训练样本保留在各轮报告所列服务器持久盘和本机归档，普通 Git 仅保存小结果、分析和哈希清单；不得将 Git 报告视为大文件的第三份备份。
