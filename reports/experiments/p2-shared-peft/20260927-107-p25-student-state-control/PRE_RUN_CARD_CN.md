# P2.5 同观测无 LoRA 对照：预注册

问题：在 data80 rank8 LoRA 自身实际访问的 140 个观测上，exact-12L 无 LoRA 相对冻结 BF16 的动作分歧是多少？与已经保存的 LoRA 同观测分歧作配对比较。只改变是否加载 blocks18–19 的 LoRA；12L 的量化 profile、种子、观测、8×7 动作语义一致。主要指标为每个观测的动作 MSE 配对差及每轨迹中位数；次要指标为逐 step、位置、旋转、夹爪符号及 margin。现有 LoRA 学生的 BF16 结果来自同一序列化观测。新 probe BF16 必须先与现有 BF16 输出核对一致性；若不一致，只报告不兼容，不做 LoRA 对照结论。

数据仅为历史开发 reset 下的 student-visited 观测，不触碰 offline_final_holdout。140 个源文件 SHA、观测 SHA 与 8×7 形状逐一复核；probe 的 dataset action 字段只用学生首步动作作格式占位，不作为标签。期望成本：两次 140 帧模型推理；不训练、不改变参数。若无 LoRA 更接近 BF16，则下一步先分析目标/分布错配；若 LoRA 更接近 BF16 但闭环无收益，则追查 8 步时位与失败状态。任一结果都不能解锁 P4/P5 或证明因果闭环收益。五小时额度到 15% 立即停止扩展并归档，10% 不启动新实验、关机。
