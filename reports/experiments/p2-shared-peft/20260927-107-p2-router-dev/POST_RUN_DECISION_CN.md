# router_dev 轨迹级 A/B/C/D：阶段决定

分类：DIAGNOSTIC。固定 exact-12L、blocks18–19、rank8 Response-SVD Smooth-L1；仅比较训练轨迹覆盖 16/80 与总优化步数 200/1000。数据来自 v3 轨迹切分中的 router_dev 59 条轨迹、每条 5 帧，共 295 帧。BF16 教师、exact-12L 和四个 LoRA 使用同一帧清单；`offline_final_holdout` 未触碰。完整逐帧指标、清单和轨迹级汇总位于同名 `results` 目录。四项评测均退出码 0。

| 格 | 轨迹/步数 | 动作 MSE 均值 | 相对12L改善轨迹 | 最差十分位轨迹退化均值 | 夹爪符号分歧 |
|---|---:|---:|---:|---:|---:|
| exact-12L | 无 LoRA | 0.05549 | — | — | 0.06695 |
| A | 16/200 | 0.05195 | 57.6% | +0.00508 | 0.06398 |
| B | 16/1000 | 0.06943 | 45.8% | +0.03548 | 0.07119 |
| C | 80/200 | 0.05485 | 57.6% | +0.00330 | 0.06525 |
| D | 80/1000 | 0.05173 | 52.5% | +0.01681 | 0.06907 |

同轨迹覆盖下，16 轨迹增至 1000 步出现明显离线退化；80 轨迹增至 1000 步改善均值，但改善轨迹比例低于 200 步，最差十分位退化更大。增加覆盖或计算均非单调有效，先前 data80 离线收益不能单独归因于覆盖，也不能外推闭环。D 的均值接近 A，但其夹爪分歧和最差轨迹退化均高于 A；不按均值选 D 做 P4/P5。上述数字是开发集描述性统计，尚无跨 seed 不确定性，也不等于闭环收益。

当前闭环稳定性试跑 data80 LoRA 为 42/50，同 slice 12L=43/50、14L=43/50；该 slice 静态 W4 headroom 为零，恢复率为 null。P2.5 学生访问状态上的 LoRA 对 BF16 仍有动作分歧，且尚无相同状态下无 LoRA 的配对控制。下一项只在这 140 个同观测上加入 exact-12L 无 LoRA 对照，先核对教师实现一致性；若不可比则不作优劣结论。研究主线仍是低成本 AWQ-W2A16 的能力恢复；P4/P5、Router、静态 W4 搜索继续锁定。
