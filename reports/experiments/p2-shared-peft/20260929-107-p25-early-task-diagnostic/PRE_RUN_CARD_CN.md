# P2.5 前三次决策同观测诊断（预注册）

状态：PRE_REGISTERED。固定 exact-12L、rank8 Recovery-LoRA 与 blocks18–19，不训练新模型。历史配对 Spatial500 中 task1 的 LoRA 有多例挽救，task2 则集中出现新增失败；此前只在学生第4次策略查询做了 no-LoRA 与14L对照。该单点不能定位误差最早出现的阶段。

本实验固定所有500个 LoRA 闭环中的 task_id=1,2 各50回合，不以回合成败筛选；对每回合 query0、1、2 的真实学生访问观测，共300个，逐样本核对源观测哈希，再用冻结 BF16、相同 AWQ 配方的 exact-12L 与静态14L在同一观测上推理。LoRA 对 BF16 的现有逐查询结果作参照。五个60样本分片自动接续，所有任务各自的所有初态均进入诊断。

主要读数为 task×query 的8步7维 raw MSE、逐维误差、夹爪符号分歧及 margin，特别核查 task2 的 LoRA 新增失败是否在早期相对12L/14L恶化，同时检查 task1 的增益是否持续。按 episode 配对统计与置信区间；成败仅用于事后解释。若 task2 的早期误差稳定恶化而 task1持续改善，下一步优先检验 shared LoRA 的目标/任务冲突及同预算单变量修正；若误差仅晚期出现，优先研究分布漂移与状态重标。若离线误差不能解释实际成败，结合视频/动作阶段复核，不把MSE视为闭环替代指标。

仅用开发初态，不触碰 offline_final_holdout，不启动 Router/P4/P5、静态W4搜索或新backbone。既有14L是冻结参照，非新候选搜索。实验代价为三个模型×300次同观测动作探针，复用已有 LoRA 与教师查询；不提供反事实闭环收益。五小时额度剩约15%停止扩展并备份，10%停止GPU并关107，留至少3%。
