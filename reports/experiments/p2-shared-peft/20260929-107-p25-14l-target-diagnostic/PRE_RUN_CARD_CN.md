# P2.5：14L 动作目标是否与 BF16 在关键状态上不同（预注册）

状态：PRE_REGISTERED，开发诊断，不训练、不改变当前 exact-12L PEFT 底座、不触碰 `offline_final_holdout`。

**问题：**现有 rank8 LoRA 对 BF16 的同观测平均动作误差下降，却未获得闭环净收益。能否观察到静态 14L 在同一批学生访问状态上的动作修正方向不同于 BF16，尤其在 LoRA 造成退化的任务和动作维度？只有看到可解释差异，才考虑把 14L 作为下一次训练的唯一教师变量。

**单一变量与控制：**固定先前 LoRA 500 回合各第 4 次策略查询（`query_in_episode=3`，执行约24步后）的序列化观测、同一 BF16 答案、exact-12L 与 LoRA 结果、probe/evaluator 配方；新增静态 14L（仅语言 blocks18–19 从 W2 升 W4）同状态推理。五个 100 样本分片由不可变顺序 runner 接续。不得用本轮评测观测训练模型，不按回合成败筛选输入。

**主输出：**14L 对 BF16 的 raw 8×7 动作 MSE、对 12L/LoRA 的动作距离；任务及位置/旋转/夹爪分层，8步位置与夹爪符号和 margin。来源样本哈希和旧教师 manifest 必须匹配；任何契约不一致即停下解释。LoRA 回合的未来成败只用于事后分层，不作模型输入。需报告参数/字节与推理时间；此探针不提供反事实闭环成功率。

**两种结果对应的决定：**若 14L 在 LoRA 新增失败任务或关键动作上给出与 BF16 稳定不同、且与 12L→14L 静态恢复一致的修正，再在 P2.5 失败时序审计后预注册同预算 BF16/14L 教师替换对照；若差异很小、方向不稳或只是平均 MSE 改善，则不换教师，转向 8 步目标权重、任务均衡或训练状态分布的单变量诊断。不得由此直接启动 P4/P5/Router。

**停止与成本：**五片合计 500 次冻结 14L 探针，估计 GPU 阶段约数十分钟至两小时，服务器持久盘预留大于 6GB；只保存小指标和 manifest，不复制已有 BF16 原始响应。五小时额度剩余约15%停止扩展并开始双份归档、GitHub 分析备份，约10%停止新 GPU 阶段并使用已核验 fallback 关闭本次 107，预留至少3%。
