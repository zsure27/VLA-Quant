# P2.5 学生访问状态重标：450 回合配对闭环结果

## 问题与对照

本轮检验旧的离线 Recovery-LoRA 为什么未带来闭环收益，以及在**相同 12L 混精 AWQ-W2 主底座**、相同语言 blocks18–19、rank8、Response-SVD 初始化、1000 优化步、uniform Smooth-L1 和学习率下，把训练观测换为学生实际访问状态、由冻结 BF16 在同一观测重标，能否恢复闭环能力。新样本为训练 reset0–3 上每任务 4 回合的 query0/1，共 80 个学生访问观测。新 LoRA 有 1,249,280 个可训练参数；adapter SHA256 为 `67cd6a6d4ec75d9173ce95b5f8f21c99b6562bfea58ea80947aa5640a335710a`。

闭环仅在未用于新候选训练的 Spatial reset5–49 上运行，共 10 任务×45=450 回合。对每回合的 task、初态编号、model/env seed 和初态 SHA 与已冻结的 12L(C0)、旧 demo-only LoRA(C1)、静态 14L(C2)逐一核对；新候选为 C3。五片执行器全部 exit0、无 episode 错误，GPU 已空闲。`offline_final_holdout` 未触碰。这里的 12L **不是纯 W2**；这些初态仍属开发证据，不是最终盲测。

## 主结果

| 配置 | 成功/450 | 成功率 |
| --- | ---: | ---: |
| C0：12L | 368 | 81.78% |
| C1：12L+旧 Recovery-LoRA | 366 | 81.33% |
| C2：静态 14L | 388 | 86.22% |
| C3：12L+学生状态重标 Recovery-LoRA | **389** | **86.44%** |

C3 相对 C0 净增 **21/450（+4.67 个百分点）**：挽救 35 回合、引入 14 个失败；按 episode 重采样的配对差 95% 区间约 **+1.56 至 +7.78 个百分点**，精确 McNemar 双侧 `p=0.00380`。相对 C1 净增 23/450（挽救 38、引入 15，`p=0.00219`）。相对 C2 仅净增 1/450（16/15，`p=1.0`），**没有证据表明它优于 14L**。静态 C2−C0 headroom 为 20/450，C3 的点估计恢复比例 21/20=105%；这个比值只描述本配对开发集，不是跨 seed 的稳定恢复率，更不说明 C3 总体优于 C2。

五片结果按初态 5–9、10–19、20–29、30–39、40–49 分别是 C3 `43/50、86/100、89/100、88/100、83/100`；对应 C0 为 `42/50、83/100、82/100、82/100、79/100`。完整逐回合配对、源文件 SHA、分任务统计和 bootstrap 种子保存在同名 `results/experiments/p2-shared-peft/20260929-107-p25-student-state80-distill/paired-closed-loop-450-analysis.json`，原始 `paired-episodes.jsonl` 在本地与服务器完整归档中。

## 异质性与失败模式

按每任务 45 回合，新候选相对 C0：task1 `1→15`（15 挽救、1 新失败），task5 `22→31`（10/1），两者净增 **23**，超过整体净增 21；task2 `42→45`（3/0）也修复了旧 LoRA 曾伤害的任务。task6 `44→41`（1/4）、task7 `40→36`（2/6）、task3 `45→43`（0/2）仍退步。task0/9无净变化；task4/8各净增1/3。任务上限效应使多数任务在 C0 已接近满分，不能把 task1/5 的改善解释为均匀恢复。

此前固定旧学生观测的 BF16 同观测诊断显示，新 C3 对 query3 的 raw 8×7 MSE 从旧 C1 的 `0.03260` 降到 `0.01915`，夹爪符号分歧 `0.06528→0.06056`，但仅 190/450 个观测逐点更好；轨迹级 router_dev 59 条中均值归一化 MSE `0.05173→0.04915`，中位帧 MSE 略变差。闭环结果为**目标/分布错配可被学生状态重标部分修正**提供了受控证据，但无法把改进唯一归因到哪一维或哪一时刻：尚需比较 C3 自身访问状态上的 BF16 同观测分歧、首次偏离和真实 chunk 的失败片段，尤其 task6/7。当前协议执行完整 8 步 chunk 后才重推理。

## 成本、门禁与下一步

新方法维持 12L 量化权重不变，仅增加约 125 万 LoRA 参数和 80 个教师重标观测；没有升 blocks18–19 到 W4。训练 1000 步；最终训练 MSE `0.000776`仅为拟合检查。五片闭环约 78 分钟（包含各片模型加载；未分离纯推理延迟），adapter 大小以归档中的实测字节和 SHA 为准；内存与部署延迟未做同协议测量，不能宣称其部署成本必低于 14L。

**Gate：P2.5 候选保留，P4/P5 与 Router 仍锁定。** 该开发集出现明确的闭环恢复，并解决了旧 LoRA 的主要负结果；但收益高度集中于 task1/5，task6/7退步，且只完成一套 seed/初态协议。下一轮先冻结此配置，在新的训练/评测 seed 或独立初态做同预算受控复现；同时记录 C3 自身 student-visited 状态与 BF16 的逐 step、位置/旋转/夹爪及首次大分歧，定位 task6/7。若收益跨 seed 不稳定，优先改进共享 PEFT 的训练分布，而不是扩 rank、增加专家或实现路由。纯 W2 作为单独更难目标，待 12L 方法稳健后再验证。
