# A1 Post-run Decision：独立条件门禁失败

**状态：`A1_INVALID_CONDITION`。** 450/配置的数值成功差为 C3−C0=+21，任务分层配对区间下界大于零且五个任务净改善；这些是同一原始初态及行为路径上的协议回归结果。相对旧运行，四组配置各 450 个逐回合成败标签全部相同；真实评测器种子调用顺序下的无模型复查显示 10 个任务的 query0 与后续 8 步观测完全相同。因而本轮没有建立独立评测条件，不能把数值门槛通过当作 A1 复现成功，不能把 450 个回合再当独立证据增加样本量。

原因定位：原固定动作预检查没有在 `env.seed` 后执行评测器会执行的 `seed_all(model_seed)`；真实顺序重置 Python/NumPy/Torch/TensorFlow 随机流，导致原预检查给出错误的独立性信号。真实策略轨迹在三个同边界 C3 分片逐字节相同，进一步支持环境 seed 未改变实际政策输入/行为；其他可能的内部随机机制仍待单独审计。

**停止决策：** 不训练 A2 新 adapter，不运行 Router/P4/P5，不尝试仅更换 `env_seed` 的更多 GPU 重复。下一研究问题是能否定义一个只改变单一评测条件、真实可观测、可重复且无训练/开发重叠的新 reset 或 post-init 扰动。先做版本化 PRE-RUN CARD 和真实评测器顺序的无模型门禁；不通过就停止 GPU。当前 110 不再有预注册且合规的下一项 GPU 实验，完成带分析备份和 SHA 核验后关机，避免付费空跑。

详细数值、失败任务、原始证据及路径见同目录 `README_CN.md`，跨运行逐回合复核见同名 results 的 `cross-run-outcome-audit.json`。
