# VLA-Quant 工作汇总（9月29日—10月12日）

1. **修正复现与长评测流程。** 发现仅更换环境随机种子并未改变真实测试初态，原长实验不能作为独立复现证据。随后补充了初始观测核验、小规模配对测试和分片审计，使后续实验能够确认模型实际面对的输入一致，避免重复测试被误计为新增证据。

2. **推进语言 LoRA 的量化恢复实验。** 在学生实际访问的观测上，用 BF16 教师提供动作监督，并将 LoRA 从少量语言层扩展到更多低比特语言层。开发集结果显示，语言扩展能够恢复较多能力，支持继续研究静态微调；同时，覆盖扩大伴随参数和计算增加，收益不能全部归因于覆盖范围。

3. **完成视觉增量与纯 W2 恢复实验。** B2 在已有语言 LoRA 上增加视觉 LoRA，未观察到稳定提升，并出现少量原本成功回合被破坏的情况。B3 在纯 W2 基底上训练语言 LoRA，显著改善量化后的严重失效，在匹配的开发对照中接近 BF16 和 W4，说明静态语言微调已能修复主要能力损失。

4. **完成 B3/B4 的扩大评测。** B4 在纯 W2 基底上联合训练视觉和语言 LoRA，与 B3 完成各300回合配对评测，两者成功率均约95%。联合训练修复了部分失败，也破坏了部分成功，整体改善较小且不确定；目前无法确认增加视觉覆盖带来稳定收益，也尚无充分依据引入上下文路由。

5. **完善代码、数据和结果口径。** 统一模型命名、训练与加载流程，识别并修正后续训练中的状态归一化问题，早期存在风险的结果保留为历史参考。明确当前训练与评测使用同一组任务、不同初态，结果支持同任务开发恢复，不能解释为未见任务泛化；同时区分了校准轨迹与学生训练观测，避免混淆数据规模。

6. **完成量化微调文献调研，收紧研究方向。** 调研确认低比特基底加 LoRA 属于常见基线，但量化误差初始化、尺度微调和学生状态蒸馏已有相关工作。后续应从 VLA 的夹爪决策、接触阶段和动作块误差累积等具体问题出发，检验能否在相同预算下优于强静态基线。当前实验验证的是低比特数值条件下的恢复，真实存储和推理效率仍需补测。

**后续短期规划：**

- 优先分析已有失败及成败翻转回合，定位夹爪、接触和动作块后段的误差，并检查训练观测是否充分覆盖这些阶段。
- 补充同预算的标准 LoRA 对照，再依据诊断结果，从尺度微调或整体特征蒸馏中选择一项开展小规模验证。
- 完善更有区分力的评测方案和真实 W2 部署检查；获得稳定互补与可预测性证据后，再考虑上下文路由。
