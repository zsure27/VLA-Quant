# P2.5：LW 学生访问状态上的同观测 BF16 教师诊断

## 固定问题与证据

本诊断读取已完成的 `first50trace-v3` 中 LW 的 50 个闭环回合，不重新训练，也不改变策略或环境。冻结 BF16 教师在学生实际访问的每个策略观测上给出动作和 H17 表征；每次推理的 8 步动作块在环境中执行后才重新推理。输入不含未来成败或专家事后信息。诊断计划 `p25-lw-teacher-diagnosis-v1-059-20261001` 退出码为 0，产物 `complete.json` 标记 COMPLETE，50 回合、678 次同观测查询均有响应，`SHA256SUMS.txt` 全部校验通过。模型配置、输入轨迹和程序哈希见同名 `results/experiments/p2-shared-peft/20260930-059-language-w2-all/teacher-on-lw-first50trace/`。

## 观察结果

50 回合中 LW 成功 48 回合、失败 2 回合（episode_serial 19、27）。按 678 次查询计，学生与 BF16 的动作块 MSE 均值 0.0220、中位数 0.0118；位置 RMSE 均值 0.1617，旋转 0.0219，夹爪连续值 0.1053，夹爪二值分歧比例均值 0.0492。逐维 RMSE 均值（动作维 0–6）为 0.1344、0.1301、0.1789、0.0129、0.0280、0.0165、0.1053；8 个执行步的 RMSE 均值依次为 0.1211、0.1178、0.1176、0.1163、0.1137、0.1117、0.1135、0.1224。

失败回合共 56 次查询，夹爪二值分歧均值 0.1674，成功回合 622 次查询为 0.0386；夹爪连续 RMSE 分别为 0.2655 与 0.0909。失败回合更长（各 28 次查询），且只有两例，查询并非独立样本；因此这只是定位夹爪时序的线索，不能证明分歧造成失败，更不能作为可路由冲突的统计证据。成功回合也有明显动作分歧，动作 MSE 不能替代闭环成功率。

H17 的最后 token 余弦均值 0.4809，token 平均表示余弦均值 0.9003。两种摘要差别较大，尚未证明哪种表征能预测 rescue/break。`first_large_policy_divergence_query` 全为 null，因为此前未从 `router_dev` 预注册“大分歧”阈值；不能事后挑阈值再称首次分歧。当前也没有对同一观测让 BF16 继续执行反事实闭环，因此没有教师接管收益的因果结论。

## 与闭环结果的关系及门禁

同条件 300 回合/配置中 LW=284、C0=244、C3=260、BF16=292、全 W4=294；LW 相对 C0 为 45 rescue/5 break。P2.5 诊断只覆盖其中 reset20–24 的 LW 学生轨迹，不应与 300 回合当成额外样本。训练、开发、诊断分布的定量三向比较与独立 A1 仍未完成。复用的官方开发 reset20–49 不构成独立复现。

目前单个共享 LW LoRA 已在该开发切片上接近 BF16/W4，Router 没有被证明必要。下一轮优先建立真正策略可见变化且与训练/开发无重叠的评价条件，并执行 `docs/EVALUATION_SMOKE_GATE_20260929_CN.md`；视觉增量 LoRA 或纯 W2 方案需先版本化目标、加载/零残差契约与短烟雾，再考虑长训练。Router/P4/P5 继续锁定。本轮没有已完成这些门禁、可立即派发的下一项 GPU 计划，因此在诊断结束后进行分析备份并提前关闭 059，避免 GPU 计费空跑。五小时额度此时实时剩余 73%，提前结束的原因是研究门禁，而非额度触阈。
