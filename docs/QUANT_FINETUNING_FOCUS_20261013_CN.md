# 2026-10-13 研究重心与评测口径

用户要求后续重心转向 VLA 量化微调方法优化。保留已完成 B5 结果作为诊断证据，暂不继续扩展 routing；下一次 GPU 运行仍由用户自行开机告知，保持原数据与 holdout 角色。此记录不启动实验，不继承上一轮 Windows 关机许可。

## 路由结果的解释

- task-only 与 B4 的450个逐回合成败标签完全相同；不是与B3相同。task-only全部6241查询均选B4。后续轨迹有两例差异，不能宣称全部动作字节等价。
- B3/B4分别425/435成功；共同成功415、仅B3成功10、仅B4成功20、共同失败5，成败不一致30/450。固定整回合事后oracle为445/450，超过B4的可补空间10/450=2.22pp；这不是动态路由绝对上界，也不能成为部署选择输入。
- B5为436/450，相对B4为6 rescue/5 break，净+1=0.222pp；任务聚类95%区间[-0.889,+1.333]pp跨零，暂无明确净优势。B4到100%的空间15/450=3.33pp；BF16的433/450不是数学上界。
- 有限互补和较小headroom支持转向微调优化；教师动作误差标签与闭环成功目标的错配也是待检验线索，尚无因果归因。

## 三个选择控制

B5输入前向前当前双图像8×8×3均值网格384维、归一化本体8维、任务指令one-hot10维，共402维；402→64→2选择器25922参数。task-only仅用10维任务输入，10→64→2，834参数，同样训练500步。random用固定种子7的随机流，每次query均匀选择B3或B4，不训练选择器。三者选择同一冻结A4底座上的冻结B3/B4专家，每8个动作选择一次，chunk内部不切换。random仅首50回合49/50，不能与完整450回合直接比较。

## 采样、训练与开发

训练：10任务×reset0–3的4初态×2个固定采集策略(B3/B4)=80完整回合。开发：10任务×reset4×2策略=20完整回合。每个回合结束后以linspace覆盖首尾、取整去重，最多保留5个query；本次每回合均取得5个，故400/100观测。query是一次策略推理并预测8×7动作，通常执行8动作后再查询；5个query不是5个环境步或5条语言提问。

同一保存观测分别交给冻结BF16教师与两专家，用归一化动作的SmoothL1(beta=0.1)误差产生偏好/损失标签，保留成功与失败回合。训练/开发内容无交集；开发只用于检查同任务新初态上的选择误差，本轮无开发checkpoint选择。开发标签16次偏B3、84次偏B4，恒选B4已有84%准确率；task-only84%、B5 88%是离线专家标签准确率，不能替代闭环成功率。该400观测属于B5选择器训练，不是B3/B4专家重新训练数据。

## 适配器成本

以下为适配器2字节/参数的tensor大小，不含底座、文件头、优化器、激活或轨迹数据。MiB=2^20字节。

|---|---|---:|---:|
| B0 | A3混精底座，语言18–19 rank8 | 1,249,280 | 2.38 |
| B1 | A3，20个仍为W2的语言block rank8 | 12,492,800 | 23.83 |
| B2 | B1冻结，新增196个视觉Linear rank8 | 19,214,848总计 | 36.65 |
| B3 | A4全合格W2，224语言Linear rank8 | 19,988,480 | 38.13 |

B2新增视觉参数6,722,048，约12.82MiB。B4从初始语言因子和视觉零输出独立联合训练，不从已训练B3继续。B5额外25922选择器参数，使用FP32时约0.099MiB。当前W2/W4底座是BF16张量伪量化，数值位宽不等于实际存储位宽，不能宣称已取得INT2部署压缩/加速。

历史同协议reset20–39的200回合：A3/B1/B2为164/194/190，A4/B3为30/192；B3有强恢复，B2视觉增量未提高B1。该历史片与新450协议分别报告，不能相减计算方法增益。新450：BF16/A0/B3/B4/B5/task-only=433/439/425/435/436/435，无完整同协议A4-450，故不能计算本轮量化缺口恢复比例。
