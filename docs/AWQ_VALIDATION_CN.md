# 固定方案的新 Spatial 轨迹验证

运行 `bash scripts/run_awq_validation.sh`。不重新校准，固定已有 W2/W4 profile，视觉 BF16、语言分别原 W2、无裁剪 W2、原 W4；同一个 BF16 教师，种子 7、SDPA、相同 32 帧。原 W4 全目标指标不能当作本轮语言 W4 的直接同范围对照，因此本轮另跑语言 W4。

新样本从原始 libero-512 中按文件名排序选择剩余 32 条 Spatial 轨迹。排除原 AWQ 64 条校准/诊断轨迹、已知旧控制用原始 0000..0007 与 0064..0071，以及 artifacts 中可解析 probe manifest 的内容哈希对应轨迹。按轨迹和内容哈希双重排除；少于 32 条则停止，不回退旧集合。复制后验证内容，保存源文件名、轨迹号、哈希和使用记录清单。新文件名 sample-1000..1031 仅用于隔离命名，真正隔离依据是轨迹与内容。

仅能保证与可核对使用记录隔离；不声称跨任务或从未被任何未记录实验使用。仍是同一套件的一轨迹一帧，不等于 LIBERO 闭环成功率或 QVLA 完整评测。方案在本轮前已固定；若根据本轮结果继续调参，则本轮数据应转为诊断集，不能反复宣称为最终测试集。

每组新进程，教师重复 MSE<=1e-10 才继续。新建 OUT，不覆盖 profile/历史结果。汇总包括平均、中位、最大动作 MSE、夹爪分歧、逐样本误差和成对改善/退化数量。只在全部完成后生成 complete.json 与保留目录结构的 review.zip，不打包权重、教师张量或原始样本。
