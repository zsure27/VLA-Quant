# PRE-RUN CARD V1：全合格量化层 W2 底座上的 Recovery-LoRA

**状态：独立预注册完成；纯 W2 profile/训练/加载代码与真实实例烟雾门禁尚未通过，不得直接启动长训练或长闭环。** 这是与视觉增量卡分开的实验，不能把 12L→纯 W2 的量化改变和 LoRA 收益混成一个比较。

## 唯一问题与名称边界

在**同一版本化全合格量化层 W2A16 底座**上，固定权重、group/clip 和评测协议后，单个 rank8 Recovery-LoRA 能否相对该底座的无 LoRA 对照改善闭环能力？主差值为 `W2+LoRA − W2无LoRA`，严格配对报告 rescue、break、净成功、任务分层、不确定性和成本。12L+LW、BF16、全 W4 仅作同条件性能参照，不能用跨底座差值推断 LoRA 因果效应。

“纯 W2”在本卡仅指**所有 AWQ 合格的视觉和语言权重目标均为 W2A16**；projector、action head、proprio、norm 等原本保护模块仍保持高精度。报告必须写作“全合格量化层 W2”，不得声称整模型每一参数都是 2 bit。历史全 W2 原始 G128 0/50、G64 注意力无额外 clip 11/50来自不同 profile，不能拿来当本卡的配对无 LoRA 对照。

## 冻结物料与唯一干预

- 新增**版本化** W2 backbone/profile 配置，列出 DINO/SigLIP 的 group、语言全部 32 blocks 的 W2/G64、attention V/O clip 与 MLP clip、保护模块、各目标 key 数及其哈希。以已经验证的量化配方为来源；不能覆盖 exact-12L 文件，也不能在训练中重搜 scale/clip/group。先对同一 checkpoint 构建 `W2无LoRA`，再在其上训练/加载 adapter。
- 首版 adapter 预定为语言 32 个 W2 block 的 attention/MLP Linear、rank8、单一静态 adapter；视觉塔保持同一 W2 量化且**不训练视觉 LoRA**。这是测试在全 W2 底座上语言 LoRA 的有限恢复能力，不能宣称视觉 LoRA 也无效。LW 的 20-block state 直接迁移到全 W2 只能单列转移诊断，不替代此处重新训练的 32-block state。
- 为避免拿 12L 策略访问的状态训练纯 W2，再把效果归因于 backbone，在训练专用官方 reset0–3 上收集纯 W2 学生访问观测，每任务 4 回合 × 前两次真实策略查询，目标 80 个观测；冻结 BF16 在相同观测上输出 8×7 标签。记录 40 条源回合、每条观测/教师标签 SHA、失败与覆盖。优化器、Smooth-L1 beta0.1、LR1e-4、1000 步、batch1、样本顺序种子与 LW 同口径；由真实目标集计算参数/字节与成本，不假定与 LW 同预算。若纯 W2 学生不能产生可用有限动作/完整观测，停止，不以 12L 数据静默替代。
- 训练 reset0–3 不进入评测。正式比较先在复用官方开发 reset20–49 上验证工程可行性，再为独立主张准备真正策略可见变化、可重复且无训练/开发重叠的新条件。`offline_final_holdout` 保持封存；任何新 reset/扰动均先通过 `docs/EVALUATION_SMOKE_GATE_20260929_CN.md`。不能用单独修改 `env_seed` 或旧 110 长评测当独立证据。

## 下次开机执行与停止点

1. 先核对实例、checkpoint、所有 profile、评测器、初态、训练输入的 SHA；输出精确 W2 目标清单。代码须允许**仅这个新版本底座**加载语言 32-block adapter，并对旧 12L 的 key/覆盖门禁保持严格；任何意外 W4/高精度目标、缺失 key 或量化差异均拒绝。
2. 做纯 W2 量化有限性、W2 无 LoRA 重载一致性、rank8 零输出等价、保存/加载全目标完整性、输入/梯度有限、冻结原权重的 CPU/小 GPU 检查，再做 10 优化步烟雾。比较量化前后 profile/clip 的实际加载记录，不靠配置文件名断言“纯 W2”。
3. 数据门禁通过后运行预注册的 1000 步训练。任何新训练样本集合、优化步数或目标范围变化都需要新版本卡。先做 `W2无LoRA`、`W2+LoRA`、BF16、全 W4 的每任务 1–2 reset 严格配对微测，检查真实命令、manifest、trace、首观测、8 步/7D 动作、异常。12L+LW 可以作为第五个同条件参照，但不进入主因果差值。
4. 微测协议通过才运行每配置最多 50 回合首片，硬 gate 只检协议、安全和数据独立性，不因初步成功率选择是否继续。后续片需预注册并锁定；开发 reset20–49 的结果只作开发结果，独立评测必须先证明新条件真实进入策略可见观测。
5. 报告每任务 `W2无LoRA` 与 `W2+LoRA` 成功、rescue/break、task-cluster 配对 95% 区间、精确 McNemar、与同条件 12L+LW/BF16/W4 的差距、训练和部署成本、失败轨迹。若有多个训练种子，应预先锁定并全部报告，不用开发成败挑一个。

**硬停止：** 目标未全 W2、profile 不同源、数据/状态重叠未审计、纯 W2 动作非有限、零残差/重载不等价、实际命令与卡不符、逐回合 trace/manifest 缺失、首片协议失败，或实时五小时额度达收尾门限，都停止扩展。任何未通过门禁的短试只记诊断，不升级为恢复结论。实例活跃时使用可恢复顺序 runner 和低频心跳；无合规后续项立即分析备份并关机。

**判定口径：** 同底座纯 W2 的正向闭环差值才支持 LoRA 恢复；即使恢复，若仍远低于 12L+LW/BF16/W4，也只说明纯 W2 路径尚未达到目标。若静态单 adapter 已接近参照且 break 很少，则优先简化部署；Router 需另行证明动作前上下文可预测的互补，不得仅按 task ID 选 adapter。
