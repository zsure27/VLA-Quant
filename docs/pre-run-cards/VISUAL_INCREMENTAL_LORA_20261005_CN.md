## 唯一问题与已有证据

固定 exact-12L AWQ-W2A16 底座和已训练的 LW 全语言 W2 rank8 adapter，**冻结 LW 的全部参数，只增加一个视觉 rank8 adapter**，能否在相同条件下比 LW 更好地恢复闭环成功，并且新增收益值得参数、字节、延迟和训练成本？主比较是 `LW+Vision − LW`，并报告两者对同条件 C0、BF16、全 W4 的差距。Router、第二个语言 adapter、量化 profile、训练数据扩容和纯 W2 均不在本实验中改变。

历史开发切片 reset20–49 上 C0=244/300、C3=260/300、LW=284/300、BF16=292/300、全 W4=294/300；LW 对 C0 为 45 rescue/5 break。剩余 8/300 是相对 BF16 的**描述性净差**，不是视觉 adapter 可恢复的保证。LW 收益集中于任务 1、5；视觉贡献不能仅凭该模式推断。

**旧门禁记录：** 2026-09-30 LW 卡规定进入视觉扩展需 LW 相对 C3 的任务聚类 95% 区间下界大于 0。保存的任务净差为 `[0,18,0,1,0,4,3,0,-2,0]`，净增 24/300；按任务重抽样的区间下界约 −0.3 个百分点，故**旧确认性放行条件未满足**。本卡依据用户 2026-10-05 的新方向仅预注册一个明确标为探索性的视觉实验；不得事后改写旧门禁、把复用开发切片当独立证明，或凭探索性正结果宣称视觉收益已复现。

## 冻结条件与唯一干预

- 底座：`configs/backbones/awq_w2a16_12l_mixed_spatial_v1.json`。DINO W2/G64、SigLIP W2/G128；语言 W4 blocks8–15/20–23，其余 W2/G64；保护模块维持原精度。LW adapter 从 059 归档中按 SHA 恢复并冻结；首次前向与原 LW 比特级/容差内等价。
- 视觉候选只包含两视觉塔中已 AWQ 量化且实际为 `Linear` 的 transformer attention/MLP 权重。目标名、shape、量化位宽、rank8 参数数、adapter 字节及目标集合 SHA 须在训练前从真实加载模型导出并冻结；卷积、projector、action head、proprio 和保护模块不得暗中加入。若覆盖范围需调整，另起卡片。
- 新视觉 adapter 使用零输出初始化；不能把只针对语言 action token 的 Response-SVD 校准直接移用于视觉 token。训练仍用已归档 student-state80 的同一 80 个观测与冻结 BF16 同观测标签、8×7 归一化动作 Smooth-L1 beta0.1、相同优化器/LR/1000 步/样本顺序种子；**只训练新增视觉参数**。这是固定数据下的覆盖增量工程比较，参数预算增加，不能把效果归因于单一层或在同预算下获胜。
- 先登记所有输入路径与 SHA：checkpoint、12L profile 三件套、LW state、student-state80 观测及教师标签、评测器、训练入口、官方初态数组。克隆实例身份和路径必须重新核验；旧 059 SHA 只作对照，不能冒充新实例实测。

## 下次开机执行与停止点

1. 完成代码审查中视觉训练/加载支持；在无 GPU 的静态检查中确认 target whitelist、参数冻结、保存/重载 key 精确匹配、错误 profile 或多余 key 会失败。
2. 在实际实例上做形状、量化权重不变、零残差输出等价、重载等价、有限梯度与 **10 优化步**烟雾。10 步仅查程序正确性，不以训练损失决定是否放行。
3. 在**复用的开发初态**上做 LW 与 LW+Vision 每任务 1–2 个 reset 的严格配对微测；保存真实命令、源码/输入 SHA、逐回合 manifest、首观测 trace、7D 有限动作、8 步 chunk、异常与耗时。微测成功率方向不决定后续样本量。
4. 通过前述协议后，仅运行每配置最多 50 回合的首片，停在硬 gate。逐项核对 trace 实际开启、初态与随机流相同、完成数和退出码；不能重演 059 首片未记录观测的错误。若声称独立评测条件，先完整执行 `docs/EVALUATION_SMOKE_GATE_20260929_CN.md` 的真实评测顺序、无模型同条件重复和策略可见输入检验；`env_seed` 数字变化本身无效。
5. 只有首片**协议**通过且新的独立条件确实成立，才按预登记剩余片比较主终点：闭环成功差、rescue、break、task-cluster 95% 区间、任务逐项损失、与 BF16/W4 的同条件差距，以及新增参数/字节、训练秒数、峰值显存和每 8 步推理延迟。旧 reset20–49 可作开发对照，不能叠加为独立样本或据其反复挑配置。

**硬停止：** 任一输入/代码哈希不符、LW 未冻结、目标集不完整、零残差/重载失败、训练或评测发生非有限值、manifest/trace/配对缺失、独立条件不可观测，或五小时实时额度触及收尾门限，立即停止扩展并保留原始产物。只使用服务器可恢复顺序执行器及约 15 分钟低频状态心跳；无合规后续项就归档同步并关当前实例。

**判定口径：** 开发片只报告探索性工程收益或负结果；正式支持“视觉增量有泛化收益”须预注册的独立条件上 `LW+Vision − LW` 为正、任务聚类区间下界大于 0、关键任务无未解释大幅 break，并且成本相对于收益合理。若静态 LW 足够好或视觉增量不稳定，保留最简单的 LW，不因 Router 目标而制造多个 adapter。
