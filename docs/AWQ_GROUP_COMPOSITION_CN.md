# 主视觉G64与融合视觉W2组合

前轮主视觉G64平均动作MSE为0.077541，相比G128的0.089529改善，但融合视觉尚为BF16。本轮复用两个现有profile，不校准、不训练、不使用独立验证集。

运行 `bash scripts/run_awq_group_composition.sh`。先检查教师重复，再复现全视觉G128和仅主视觉G64两个参照，最后运行组合。所有组的语言均为W2/G128且取消语言裁剪；视觉保留裁剪。组合只把主视觉的93个条目换成G64，融合视觉105个条目与语言224个条目继续使用原G128 profile。422个既定目标均为W2，不意味着projector、head等排除模块也量化。

比较组合与全G128可判断分组收益是否保留；比较组合与仅主视觉G64可判断加入融合视觉W2的影响。关注逐样本动作MSE、夹爪分歧和projector特征误差，不只看均值。若改善，再做独立验证；若不改善，先分析误差组合而非立即训练。

输出review.zip不包含模型权重，原profile不修改。本轮是BF16承载的模拟量化离线诊断，不代表真实INT2速度、内存或闭环成功率。
