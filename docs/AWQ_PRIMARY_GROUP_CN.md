# 主视觉 W2 分组大小对照

前轮取消主视觉裁剪使平均动作误差由0.089529升至0.106411，因此本轮保留视觉裁剪。运行 `bash scripts/run_awq_primary_group.sh`。

固定教师为原始BF16 OpenVLA-OFT Spatial，语言为原profile的W2/G128且取消语言裁剪，融合视觉保持BF16。只将93个主视觉目标从W2/G128换成重新校准的W2/G64。缩小分组可能改善量化分辨率，但增加缩放和零点的元数据开销；不改变权重位宽，不代表实际INT2加速。

为保留完整profile格式及来源校验，校准阶段生成422目标的完整G64 profile。推理只选取其中93个主视觉条目，其他条目不使用。该策略有额外校准成本，并非只校准主视觉。原profile、教师、模型文件不由本脚本覆盖。

校准使用原32帧、seed7、max_rows1024、max_output_rows256、clip_tokens128及官方block搜索设置。诊断使用原offset32的32帧，不使用新增独立验证集。分组变化后重新搜索scale/clip是完整G64算法设置的一部分，因此不能进一步声称收益只来自量化间隔而与重新搜索无关。

执行顺序：运行时与轨迹分离检查、教师重复、G128旧结果复现、G64校准、仅主视觉G64推理、范围和指标汇总。任意失败停止。请保留打印的OUT；校准较耗时，避免直接关闭终端。review.zip不含pt权重，但服务器上的G64 profile应保留供后续使用。

若G64同时改善特征误差和动作表现，下一步测试与融合视觉W2的组合；若不改善，不继续盲目缩小分组，优先考虑量化输入路径感知校准。最终候选仍需独立验证和闭环rollout。
