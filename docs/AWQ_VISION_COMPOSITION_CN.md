# 无裁剪语言 W2 与视觉量化组合

运行 `bash scripts/run_awq_vision_composition.sh`。回到旧 Spatial 诊断集 0032..0063，固定原 32 校准轨迹生成的 W2/W4 profile，不重新校准，不使用新验证集挑选方案。每组新进程，种子7、SDPA、BF16教师一致。

先教师重复控制，再复现旧无裁剪语言 W2 参照；平均之外，逐样本动作 MSE 差必须 <=1e-8，夹爪分歧一致，否则停止。随后比较视觉 W4 + 语言 W2 无裁剪，以及视觉 W2 + 语言 W2 无裁剪。视觉使用原有视觉适配条目的 scale/clip，不取消视觉裁剪；只有语言160个原有裁剪目标移除 clip_max。Q/K 原本不裁剪。

视觉 BF16 组224语言目标；视觉 W4 组198视觉W4 +224语言W2；视觉 W2 组422个目标W2。激活仍A16，projector、动作头、本体投影等不低比特量化。视觉 W4 必须使用独立 W4 profile 的视觉条目，语言始终使用 W2 block 配对缩放；不将语言的 W4 缩放应用到模型，不混用视觉位宽参数。

这是 fake quant 诊断，视觉逐Linear/Conv仍为明确标注的适配方法，不是原生官方整VLA AWQ recipe。取消裁剪组合是修改候选，不替换原基线。指标为对教师的离线动作一致性；不能用两个分支的单独误差简单相加推算组合误差。

scope.json 记录每个实际目标位宽、视觉组合开关和 language_only 裁剪干预范围。全部完成才生成 complete.json 与 review.zip。任何组失败保留目录和日志，不自动缩小预算或放宽阈值。

新验证集结果仅用于已有语言候选的外部检查，不加入训练。后续若视觉W2导致主要新增损失，再做projector恢复的受控验证；若视觉W4组合已明显退化，也需先核查语言/视觉交互，不直接认定projector微调一定有效。
