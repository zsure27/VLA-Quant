# 主视觉 W2 裁剪单因素对照

目的：区分主视觉误差中额外权重裁剪的影响与剩余 W2 量化误差。前轮主视觉单独 W2 的平均动作 MSE 为 0.0895293，融合视觉单独 W2 为 0.0628214；语言 W2 无裁剪、视觉 BF16 参照为 0.0563308。这只能确定当前配置下的排查优先级，不能将两分支损失简单相加。

运行 `bash scripts/run_awq_primary_clip.sh`。先重复教师，再复现前轮主视觉结果，最后只取消主视觉条目的非空 clip_max。保留原 input_scale、group_size=128、W2 量化器及语言 W2 无裁剪设置。融合视觉仍为 BF16；这是定位实验，不是全模型 W2 的最终方案。教师为同一未量化、未平滑的 BF16 OpenVLA-OFT Spatial。

脚本复用原校准 profile，使用原 32 个诊断样本，不触碰后续独立验证集、不训练、不重新校准。分别记录语言和视觉移除裁剪的目标，原 profile 不修改。这里的无裁剪不是删除量化器自身的整数范围截断。

检查均值、中位数、最大动作误差、逐样本改善数和 256 个夹爪指令分歧，并结合输出中的 projector 与语言特征误差。若改善，再测试融合视觉重新加入 W2 后的组合；若不改善，优先考虑重新校准的分组大小对照或量化路径感知校准。不要仅凭本轮离线误差决定训练或宣称成功率恢复。

仅全部检查通过才写 complete.json 和 review.zip。失败时保留目录排错，不放宽门槛。此处仍为模拟量化，不代表实际 INT2 存储或加速。
