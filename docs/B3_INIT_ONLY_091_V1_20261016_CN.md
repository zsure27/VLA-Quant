# 091：A4 PTQ与SVD仅初始化机制对照

新入口 `qvla/run_eval_b3_init_only_091_v1.py`；独立身份 `b3-init-only-091-v1-20261016`。
不修改旧B3训练入口、旧artifact或旧validator，不将S0伪装成完成1000步的B3。

## 两个候选与参数

- `--candidate ptq --model-id A4`：canonical A4量化计划，无adapter，优化步数0。
- `--candidate svd-init-only --model-id B3-S0-091-v1`：相同A4，加载046 S的训练前`initial-adapter.pt`，224语言Linear/rank8，BA不额外缩放，优化步数0。

两者共同传入：

```
--method awq --weight-bits 2 --activation-bits 16
--profile <冻结W2-G128 profile>
--awq-primary-group64-profile <冻结W2-G64 profile>
--awq-candidate w2-attention-no-clip-primary-g64
--official-root <official_root> --pretrained_checkpoint <完整checkpoint>
--libero_root <libero_root> --task_suite_name libero_spatial
--initial-state-offset 5 --num_trials_per_task 5
--seed 0 --env-seed 1 --seed-protocol paired
--trace-actions --trace-observations --local_log_dir <本候选唯一输出目录>
--initial-artifact <046 response-svd/steps-1000/artifact.json>
--initial-artifact-sha256 <由已验证046归档取得、写入不可变plan的SHA>
--initial-state <同目录initial-adapter.pt>
--recovery-training-manifest <旧A4 student80/manifest.json>
```

`initial-artifact`仅证明初始化来源及冻结底座身份；不会加载其已训练`adapter.pt`。
`initial-state`必须同时匹配父artifact的`reuse_files`/`inherited_initial_factor_sha256`与原spec的固定初始因子SHA。
父artifact的最终adapter形状只作目标/形状校验，不表示S0训练过。

## 门禁

1. CPU纯metadata契约：`scripts/check_b3_init_only_091_cpu_v1.py --output <新gate.json>`。
   包含错误初始因子角色、step、proprio、冻结SHA、rank、缩放、预算、目标、shape和数据角色反例。
2. 入口实际核对父artifact显式SHA、旧source/spec/训练manifest SHA、两profile SHA、完整checkpoint内容、official AWQ源码、422量化目标及224语言rank8目标。
3. 首个真实query在原部署`get_action`上做独立raw observation副本检查：同一归一化规则只执行一次；S0原值→B置零→磁盘重新加载S0→输出逐位一致；模型/head/proprio完整冻结SHA与046训练前一致。
4. 额外探针保存并恢复Python/NumPy/CPU/CUDA RNG；正式observation不在探针中被改写。正式调用仍采用原配对评测器、8步chunk、真实动作/观测capture。
5. 首query门禁写`actual-model-init-only-gate.json`，候选来源写`candidate-init-only.json`。配对audit须将S0 gate中的`zero_branch_action`与A4在**完全相同首观测**的实际动作比较；不能只比较成功标签。也须核验原argv、全部episode/reset/首观测SHA、finite/异常/退出码。

CPU通过不是GPU通过。先micro每配置10，再正式首50每配置50；后续总量由预注册研究问题/资源/gate决定。旧Z/S450只作冻结历史开发参照，不相加为新独立重复。

```
python scripts/audit_b3_init_only_091_v1.py --root <phase目录> --offset 5 --count 1 --output <micro-gate.json>
python scripts/audit_b3_init_only_091_v1.py --root <phase目录> --offset 5 --count 5 --output <first50-gate.json>
```

phase目录下固定`ptq/`、`svd-init-only/`。复用旧`audit_case`而不放宽旧validator，额外复核新候选来源、实际首query门禁与S0零分支等于PTQ首动作。输出`PASS_B3_INIT_ONLY_PAIRED_PROTOCOL`、配对行、rescue/break、任务bootstrap、McNemar、全部失败与成本。`count`只允许1或5、offset固定5，不能经此入口直接放行长片。一次纯CPU合成正例与三项反例已验证：零分支错、实际首动作错、非0优化步数均被拒绝；这不代替真实GPU运行审计。

## 成本与实现范围

评测无教师重标或训练；S0初始化材料的历史校准/SVD成本另列。运行时只保留一个7B模型，初始化辅助head/proprio在评测前释放；不生成激活spool。冻结SHA首query扫描开销与额外2–3次前向单列，不能混入纯forward延迟。
首query冻结底座SHA失败不得放宽阈值；应定位checkpoint/profile/模型/head/proprio身份。
