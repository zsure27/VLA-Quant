# AWQ 单块综合诊断

运行 `bash scripts/run_awq_block_audit.sh`。默认复用 20260912 Spatial 实验目录，也可显式传 BASE。仅新建输出，不更新模型、profile 或教师缓存；约需一份语言模型大小的 CPU 权重快照，GPU 仍只加载一份模型。

选取诊断样本 35（早期异常）、48（晚期异常）、57（相对稳定），检查 0 起始层 10、11、12、25、26。它们是根据既有结果选择的案例，不是无偏测试集。共 3×5×2×8=240 条局部对照指标，不是 240 次 rollout。

先重放完整 BF16 和仅语言 W2，要求教师误差 <=1e-10、W2 相对旧动作 MSE 差 <=1e-8；不通过则停止，不自动放宽。捕获每帧真实 block 输入和 mask/position 上下文，不拼接帧，不启用 KV cache，不改 eager attention。动作 token 范围由实际回归调用参数捕获。

两种输入：教师路径、仅语言 W2 路径。每种输入比较 BF16、W2 只缩放、W2 缩放+裁剪不量化、W2 缩放+量化不裁剪、完整 W2、W2 保护 attention、W2 保护 MLP、独立 profile 的完整 W4。保护指跳过该子模块的裁剪与量化，仍保留所有配对缩放；不是恢复原始未经缩放的权重。无裁剪组不重新搜索 scale。

`same_input_error` 以同输入的 BF16 块为参考，定位本块变换误差；`vs_teacher_path` 以教师路径输入的 BF16 块为参考，包含上游扰动。两者均报告全序列和完整动作读出 token；不能把全序列均值替代动作特征误差，也不能简单相减作为因果贡献。局部保护输出不继续送入后续层，不能据此宣称端到端动作已恢复。

每个变体前恢复完整块参数；同输入重复检查、实验结束后整模型恢复检查。只有全部完成才生成 complete.json 和 review.zip，部分 metrics.json 不代表完成。

CPU 单测覆盖干预路由、位宽、profile 不变性、裁剪和 token 切片；不能替代真实 OFT/SDPA/GPU 重放测试。未修订现有适配器，以保持既有 profile 的源码校验有效。

注意：现有 profiles/w2.json 与 w4.json 的 mean_relative_mse 来自视觉逐 Linear 条目，不包含语言 block，不能解释成全模型平均校准误差。
