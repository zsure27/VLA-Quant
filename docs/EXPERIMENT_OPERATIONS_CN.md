## 每项研究与每轮运行

用户下发任务和已开启的服务器后才开始。先核对服务器型号、hostname、SSH身份和磁盘/GPU；检查点按实际内容SHA识别。任务定义研究问题和唯一变量，运行轮次只记录执行过程。后续补跑合入同一中文任务文件，不再为每轮另建一套reports/results。

起跑前写实验卡：suite和数据角色、量化配方、微调方法、对照、样本/训练预算、候选筛选停止标准、成本上限、额度门限、服务器及关机机制。默认多类小样本探索，结果明显即停止，不机械扩充450。新方法12GiB盘余量、续片8GiB、运行6GiB作为默认资源门禁；显存需求按本次真实方法核验。

## 心跳和结束条件

默认15分钟心跳，只读status及实际进程/GPU/盘；状态未变静默。阶段变化/失败/完成/阈值才通知。GPUutil为0不能独自判定卡死，要结合CPU、显存和进程。额度使用当前5小时primary API；默认15%停止扩展并保存，10%开始终止与收尾，留3%。实际API确认窗口改变才算刷新；不使用额度券。

结束条件包括任务完成、额度阈值、无法解决的实验/授权问题。先输出问题，然后保护已有数据并关闭当前付费实例。若授权本身阻止关闭，明确告警并保留收据，不能绕过审批或声称已关。平台状态与计费不能用SSH断开推断。

## GitHub优先备份

同一轮运行期间，阶段状态、原始输出和日志先保存在服务器持久盘；不因每个回合或每次阶段完成就提交或上传 GitHub。达到本轮结束条件后，集中审计代码、数据、失败记录和分析，做一次完整的私有原始数据归档及一次公开代码/小结果 Git 同步，并分别验证远端内容与提交 SHA。若额度或故障迫使提前结束，已产生的部分数据也在该次收尾中集中保存，明确标记未完成范围。

| 材料 | 位置 | 要求 |
|---|---|---|
| 代码、配置、综合分析、少量统计、恢复索引 | 公开VLA-Quant普通Git，`Ex_Reports`统一入口 | 先检查凭据及公开范围，再提交明确文件，核验远端commit |
| 原始观测/动作、视频、checkpoint、完整日志、大归档 | 私有VLA-Quant-Archives的Release | 仅打包新增数据，内容寻址复用；凭据扫描、大小/digest、逐块下载SHA与成员恢复清单 |
| 未上传或上传失败材料 | 当前服务器持久盘 | 保留，不删除；报告尚未云端验证的范围，仍按当前关机授权停止实例 |

备份先列明内容与网络预算。压缩包N字节，至少上传N+下载校验N；重试和协议开销另计，不把最低值称为实际总流量。不重复全量下载/打包完整历史阶段。工作机只留小结果/恢复入口；服务器已有不可变父材料通过SHA与私有恢复引用登记，不每轮复制。

本轮打包必须包含输出及当前argv、配置/计划、模型/数据/profile/source身份、成功失败中断事实和成本；父数据、模型及源码依赖以可恢复引用明确列出。`infra_archive_run.py`的范围是当前run目录，不自动声称包含外部7B模型和所有父数据。外部依赖若无可恢复副本，标注缺口并保留服务器原件。默认上传预算2GiB，超出时保留压缩包并报告，不暗中耗费大量流量。

备份完成不自动删除数据。只有远端完整恢复门禁通过的非必需本地副本，才按精确绝对路径、大小/SHA及授权范围清理；不跟随junction/reparse。B5历史归档缺前缀，仍是部分备份。

## 关服务器是每轮必要步骤

1. 保存已有进度；停止本轮子进程组，保留中断事实，不伪造exit0。
2. 写清问题/结果与成本，保存持久盘成员清单并尝试云端备份；更新任务文档和恢复索引。
3. 同步本轮代码修改与小结果到Git，核验远端SHA。失败则记录具体缺口，保留持久盘，仍尝试停机。
4. 核验当前hostname、GPU闲与原生停机机制；发出当前实例关机请求并保存真实收据。不清Trash，不开新实例。
5. 控制端收集/补录关机回执，确认平台OFF/计费则单列证据，暂停对应心跳，发送完成或阻断摘要。

当前内置原生提供者为AutoDL已观察的supervisord机制。新增云平台必须单独实现并验证provider，不对未知平台直接套用。关机被授权系统拒绝时不能绕过；用户需要知道实际未关闭，而不是收到虚假的完成通知。Windows正常关机需要该轮独立明确授权，框架默认保持本机开启。
