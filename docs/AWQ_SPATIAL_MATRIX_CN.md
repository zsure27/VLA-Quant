# AWQ Spatial 主线

先运行 `STAGE=w4 bash scripts/run_awq_spatial.sh`，审阅 W4 结果后，再指定同一 OUT 运行 STAGE=w2。禁止将 W4 搜索结果用于 W2。

现有 Spatial 样本按文件名选前64个不同轨迹：32校准、32诊断，每条一帧。它们不是最终未见测试集，也不是论文完整校准协议。保留原文件及来源哈希，不混合其他套件的统计。

共同控制为固定源码/运行时、完整422目标、轨迹划分、BF16重复性。AWQ 使用官方 Llama block 搜索和内部缩放等价性检查；视觉部分仍为已声明的逐Linear适配，不能称为整模型原生官方AWQ。SQ平滑失败不阻止此独立方法，但不可据此标记SQ通过。

W4全目标是参照，W2全目标/视觉/语言/教师projector替换用于定位。全部为fake quant，不提供真实INT2速度或内存收益证明。32帧官方搜索可能耗时或显存不足，报错保留日志，不自动缩小预算或切换算法。

新入口仅本地语法及样本划分逻辑验证；GPU实际运行由用户完成。
