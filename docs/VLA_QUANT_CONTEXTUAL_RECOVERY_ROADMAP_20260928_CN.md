# VLA-Quant：低比特恢复与 Contextual Routing 研究规划（修订提案）

日期：2026-09-28。状态：**研究规划提案，不解除现有实验门禁**。本文依据用户提供的核心 baseline、现有原始结果及 [P2.5 方案](P2_5_ON_POLICY_ALIGNMENT_PLAN_20260926_CN.md)整理；具体运行仍遵守 [研究自纠偏决定](RESEARCH_DIRECTION_CORRECTION_20260927_CN.md) 和 [执行协议](PEFT_CONTEXTUAL_ROUTING_EXECUTION_20260925_CN.md)。用户已确认先以 12L mixed 底座建立方法，纯 W2 后续单独验证。107 本轮已取得原生关机执行回执，本文不派发服务器实验。

## 1. 研究目标与需要分开的两条命题

长期目标是在可核算的参数、显存、延迟和训练成本下，使 AWQ 低比特 OpenVLA-OFT 保持高闭环成功率。当前可执行的因果链为：

`量化损伤定位 → 固定 12L 底座上的共享 PEFT 恢复 → 两专家互补 → 推理前上下文可预测 → Top-1 Contextual Routing`。

必须分别检验：

1. **动态恢复**：固定量化权重，依据因果上下文选择轻量 adapter。这是当前 P2–P5 路线。
2. **动态精度**：运行时切换 W2/W4 权重或精度路径。这需要额外权重驻留、切换机制、内核和端到端成本证据；仅实现 adapter Router 时，不在题目或贡献中声称完成动态精度分配。

当前 12L 底座是 **mixed W2/W4**：视觉 DINO W2 G64、SigLIP W2 G128；语言 W4 blocks 8–15、20–23，其他语言块 W2 G64；保护模块保持高精度。它是恢复机制的受控研究平台，**不是纯 W2**。纯 W2 是条件成立后另立版本的更难目标，不能把 12L 的结果移植为纯 W2 的结果。

## 3. 对上传 baseline 的关键修正

### 3.1 14L 教师是可检验的 P2 变量，不是自动更好的标签

“LoRA 能否替代两个 W4 block”与“逼近 BF16 动作”是不同问题。可在**同一 12L 底座、同一训练轨迹、rank8、blocks 18–19、初始化、优化步数和损失形式**下，仅把教师从 BF16 改为 14L。14L 教师的闭环为 431/500，低于历史 BF16 的 487/500；贴近 14L 动作不保证贴近最佳动作，也不保证净成功率提高。正式训练前先在任务及阶段均衡的固定观测上测量 BF16、14L、12L、当前 LoRA 的动作差异与 14L 特有的关键修正；只有明确区分两种目标，才预注册一次教师替换试验。评估同时报告对 14L 和 BF16 的误差，以及 12L/LoRA/14L 的配对闭环。

恢复率 `RR=(S_LoRA-S_12L)/(S_14L-S_12L)` 只在**同一配对协议且分母严格大于零**时定义；零 headroom 的 50 回合 slice 必须记为 `null`。本轮点估计为 `(408−411)/(431−411)=−15%`，区间很宽，不能写成稳定的负恢复能力。

### 3.2 “纯 W2 + 敏感层 LoRA”需另立底座版本

历史完整 W2 配方在小规模开发回合上曾显著失效，但 G64/G128、clip 与其他条件不同，尚无当前协议下的纯 W2 配对 Spatial500。要提出纯 W2 主结果，先固定可复现的纯 W2 配置、参数和 evaluator，再运行配对基线。跨层隐藏态差 `H_l^BF16−H_l^W2` 混合了前面所有层的累积误差，不能单独证明第 `l` 层应加 LoRA；应在同观测和固定上游激活下结合**局部响应误差、动作敏感性与受控干预**定位层，且预先限制候选数和预算。这是新的 backbone/目标层决策，当前 blocks 18–19 的 P2 门禁不会被本文自动更改。

### 3.3 救回/新增失败是机制线索，尚非 Router 证据

一个 shared adapter 的正负翻转可由训练目标、任务权重、动作阶段、轨迹分布或随机闭环扰动造成。应先比较 25 个救回与 28 个新增失败的首次**实际控制失败**、任务阶段、8 步位置、7D 动作及 BF16/14L 差异；对本轮 27 个“12L 失败且 14L 成功”的回合只做事后机制分析。若各阶段梯度或修正方向稳定相反，且在不同轨迹/seed 复现，才有 H2 上下文冲突证据。只有训练出两个同底座、同模块、同预算的独立专家并证明双向互补，才能测试 Router。事后成功并集是不可部署上界，不是路由性能。

### 3.4 方法贡献必须包含部署成本

12L、14L、16L、纯 W2、单/双 adapter 和 Router 分别报告**实际**权重文件字节、GPU 峰值、加载常驻量、每个 8 步 chunk 的推理延迟及吞吐、路由/切换开销与闭环成功率。名义 2/4bit 不能代替真实内核和显存收益；当前 AWQ fake-quant 结果只能证明策略行为，不直接证明整机量化加速。多专家模型须与相同总参数/显存预算的简单共享方法比较。

## 4. 可执行顺序与停止条件

| 阶段 | 最小实验与唯一主要改变量 | 放行或停止决定 |
|---|---|---|
| P2.5-A：现有轨迹复核 | 审计 411/412、430/431 来源；对 25 救回/28 新增失败做盲于候选输出的阶段与首次失败标注；比较同任务、同阶段、同 8 步位置的 BF16/12L/LoRA。保留未标注项为 `null` | 若无法定位稳定失败窗口，先改善观测/标注契约；不靠均值指定新 loss |
| P2.5-B：目标诊断 | 在同观测上加入 14L 教师；并按任务、阶段、夹爪转换及 8 步位置报告尾部风险。先完成 7D 教师数值等价与 0.5 阈值/符号契约 | 若 14L 与 BF16 在关键修正上不同，提出一次**教师替换**；若晚期动作是主要风险，提出一次**时间权重**；二者不同时变 |
| P2.5-C：唯一共享 PEFT 修正 | 固定 exact-12L、blocks 18–19、rank8、同训练轨迹与优化预算，按 B 的证据只试一个变量：教师目标、8 步权重或轨迹均衡。若阶段匹配后确证学生状态分布错配，则从**训练 reset**采集学生状态并同状态教师重标，仍只改变训练分布 | 与原 shared LoRA 及同预算简单控制比较；router_dev 的最差轨迹、夹爪和逐步指标不得被平均值掩盖；随后做冻结配对闭环与受控 seed 复现。无稳定净收益则不宣称 shared 恢复 |
| P4：两个专家 | 仅在 P2.5 处理 H1 后仍有可复现 H2，或 shared PEFT 已获稳定闭环收益时提出。专家同底座、同模块、同 rank/每专家预算，仅训练上下文分布不同 | 各专家独立闭环；与最佳固定专家、共享同总预算 adapter、事后 oracle 比较。若一方支配、oracle gap 很小或互补不跨 seed，停止 |
| P5：Contextual Routing | 专家冻结后，先从 block17 后/block18 前的因果 H17 提取特征，每 8 步选一次 Top-1；训练标签仅用可部署时可得信息 | 对最佳固定、shared、随机、instruction/task-ID 简单规则、打乱上下文及不可部署 oracle；须在锁定评测上超过最佳固定与简单规则，且扣除成本仍有收益。任务 ID 若来自未来标注，只能列为 oracle |
| 条件分支：纯 W2 | 另立版本化纯 W2 底座、动作敏感性定位和层预算；不得把 12L 结果改名或在现有 P2 内暗改目标层 | 先验证纯 W2 闭环与受控恢复，再决定是否迁移 P4/P5；可以与 12L 主结果并列报告 |
| 独立扩展：W/A | 主线稳定后再研究 SmoothQuant；先证明未取整的平滑变换在 VLA 全路径数值等价，再隔离激活位宽效应 | W4A16/W4A8 应尽量固定同一权重配方与评测契约。SmoothQuant+PEFT 与 AWQ+PEFT 分开归因，不直接宣称迁移有效 |

所有 GPU 实验先写 `PRE_RUN_CARD`：一个可证伪假设、唯一改变量、配对 manifest、主指标、正反结果各对应的决策、预算与停止条件。初期筛选只用 `peft_train/router_dev`；最终协议在候选、目标层、Router 特征和阈值冻结后才触碰留出闭环。优先报告绝对成功数、配对翻转、按任务结果与区间，不用单个恢复率代替完整证据。

## 5. 待用户确定的战略问题与建议默认值

1. **最终主结果必须是纯 W2 吗？已决定。** 用户确认先以 12L mixed 底座建立可复现的恢复与路由机制，再把纯 W2 作为独立的强化目标；两者命名和结果表始终分开。迁移纯 W2 时另立版本化底座与配对基线。
2. **最终贡献是动态 adapter，还是运行时动态 W2/W4？** 建议本阶段只承诺动态恢复。只有实测权重切换、内核与成本后，才把 adaptive precision 写入贡献。
3. **下一次共享 LoRA 的唯一变量是什么？** 建议先做 P2.5 失败与阶段定位，再在 14L 教师、8 步时间权重、任务均衡或训练 reset 重标中选一个；不能并行改变教师、训练分布和目标层。
4. **14L 是目标还是参照？** 建议保留为静态 W4 恢复参照和候选教师；BF16 同时作为动作保真护栏，避免只向 14L 拟合却牺牲控制质量。
5. **论文最小成功标准是什么？** 建议至少要求对最佳固定/同预算简单方法的锁定配对闭环净收益、跨 seed 稳定、任务退化可解释，以及真实字节/延迟成本。若这些门禁未通过，文章应如实报告静态混精与 PEFT 的边界，不预写 Router 贡献。

## 6. 外部工作定位

[QVLA](https://arxiv.org/abs/2602.03782)提出以动作空间敏感性指导通道位宽；[QuantVLA](https://arxiv.org/abs/2602.20309)研究 VLA 的选择性 PTQ 与尺度校准。这些工作支持“动作结果应进入量化评价”的研究动机，但**不证明**我们的任务阶段冲突或 Contextual Routing 必然有效。原 [SmoothQuant](https://arxiv.org/abs/2211.10438)通过等价平滑迁移激活量化难度；它对当前 OpenVLA-OFT、W2 与 8 步控制的收益仍须独立验证。用户上传文本内的 `:chatgpt-content-reference{...}` 不是可复核引文，本规划改用原论文链接。
