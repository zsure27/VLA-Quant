# AWQ 端到端裁剪与混合精度干预

运行 `bash scripts/run_awq_e2e_interventions.sh`。沿用现有 Spatial 32 条诊断轨迹、BF16 教师、种子 7、SDPA，不重校准、不覆盖原输出。每组新进程。先运行教师重复性和原语言 W2 重放控制；任何失败停止。

四组分别为：语言 W2 全部不裁剪、仅 attention 不裁剪、仅 MLP 不裁剪、仅第 10/11/12 层（0 起始）用完整独立 W4 profile，其余语言层 W2。所有组视觉 BF16，不使用 projector oracle，激活 A16，未量化动作头。Q/K 在原官方 recipe 中本来不裁剪，因此 attention 取消裁剪不等于四种投影都发生变更；scope.json 记录真正移除裁剪的目标。

无裁剪组仅去掉 clip_max，原 W2 配对 scale 不变，不重新搜索。混合位宽以整块为单位，选中块的所有配对缩放、7 个 Linear 的权重裁剪及量化都来自 W4 profile；不存在 W2 scale 搭配 W4 已缩放权重。scope.json 记录实际位宽，不能将混合精度候选称为全 W2。

完整语言权重量化仍为 224 个目标；混合组 21 个 W4、203 个 W2。只允许本阶段的 language W2A16 参数组合，不与取消裁剪或 oracle 叠加。W2/W4 必须同检查点、校准样本、组大小、源码及种子。

输出 summary.json 包含逐样本动作误差、平均/中位/最大动作误差、夹爪分歧和首次特征相对 MSE>1 层。相对 MSE>1 只是定位阈值，不是成功率；不把均值改善等同每个样本改善，也不将无裁剪诊断冒充未经修改的官方 AWQ 基线。后续仍需要独立样本与闭环验证。

此前单块结果提示：裁剪在教师输入上改善平均误差，但与 W2 量化组合后在部分上游扰动输入上放大误差。这是本轮可检验假设，不是代码错误已确诊。GPU 实验完成后再决定是否采用选择性裁剪、混合精度或量化路径校准。
